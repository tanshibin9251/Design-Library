Configure Global Colors & FontsGuide2/4Oct 16

How to do it(2 ways — pick one)

AThrough Elementor Site Settings
  1. Open any page in Elementor, then click the hamburger menu → Site Settings.
  2. Choose Global Colors. Edit Primary, Secondary, Text and Accent — leave the system names alone.
  3. Under Global Fonts set the heading and body families, then press Update.
  4. Reload the staging site and check one page on a phone before moving on.
Screenshot: Site Settings › Global Colors with the four system slots visible
Don’t rename the four system colours — every widget is bound to those slots.

Best for: sites already built with Elementor Pro

BThrough the theme’s customiser
  1. Go to Appearance → Customize → Colors & Typography.
  2. Paste the client’s hex values into the four brand slots, then pick the two fonts.
  3. Publish, then clear the page cache so the new values show up.

Best for: block themes and lightweight starter themes
