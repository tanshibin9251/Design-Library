Web Dev 101

Eight weeks from a blank file to a deployed multi-page site. Beginner friendly; no prior coding needed.

// syllabus
Week 1 · HTML you will actually use

Elements, semantics, forms, accessibility basics. Project: a personal page.

Week 2–3 · CSS layout

Flexbox, grid, responsive design. Project: a magazine layout.

Week 4–5 · JavaScript fundamentals

Variables, functions, the DOM, events. Project: an interactive gallery.

Week 6–7 · Fetching data

fetch, JSON, loading states. Project: a weather dashboard.

Week 8 · Ship it

Git, deploy and a code review. Capstone.
