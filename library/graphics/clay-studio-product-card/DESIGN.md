# Clay Studio Product Card · 陶土影棚产品图

产品图 · 1080×1080（正方形，电商主图 / 社交帖文通用）· 风格 clay / pastel / minimal · 行业 beauty / lifestyle

## 构图特征（这套的灵魂）
- 画面分三层：**墙面**（上 2/3，陶土渐变）、**地面**（下 1/3，同色加深 35%）、中间的**圆形基座**（椭圆，带内侧底边与软阴影）。
- 墙上一个**大实心圆**（主色，直径 ≈ 画面 48%）作为产品背后的「太阳」，只露出圆弧，不做渐变。
- 产品居中站在基座上，**占画面高度 40–45%**；产品必须是透明 PNG，加一个低对比的接触阴影，不要硬投影。
- 左上品牌名（衬线），右上编号小字；**3 个药丸形卖点标签**错落分布在产品两侧（圆点用强调色），不压住产品。
- 左下产品名（衬线 64px）+ 一行小字类别，右下价格用主色。
- 全幅只有「陶土 + 奶油 + 一抹鼠尾草绿」三个色系，没有纯黑纯白。

## 不要
- 不要真实相机滤镜、镜头光晕、反光；不要多个产品同框（一个系列图另做）。
- 不要卖点标签超过 3 个或每个超过 3 个词；不要加折扣红标。
- 不要让主色圆和产品同色（产品要比圆浅）。
- 不要用 3D 渲染质感做假阴影；阴影只用低透明度的暖棕色。

## 文案口吻
成分 / 容量 / 功效三选三，用名词短语，不写形容词堆叠。

## 中文版
产品名用 Noto Serif SC 500；标签用 Noto Sans SC 500；价格前加「¥」。中文标题不要斜体，字距 0。

## 用法
1. 颜色字体只改 CSS 变量。
2. 产品图缺失时保留「缺图」位并告诉用户；有产品图则替换 `.item` 为 `<img>`，保持底部贴基座。
3. 换色时让「墙面 / 地面 / 圆」三层保持明度差，先过对比检查（文字/底色 ≥ 4.5）。
4. 浏览器 1080×1080 视口截图导出 PNG（电商平台主图一般要求 ≥ 800×800、白底版另出一份）。
