# Neobrutal Tutorial Thumbnail · 新粗野教学缩略图

缩略图 · 1280×720（YouTube 16:9）· 风格 neobrutal / bold / playful · 行业 coding / education

## 构图特征（这套的灵魂）
- 满版**高饱和黄底**（主色）+ 14% 黑点阵纹理，其余全是**黑色 8px 粗描边 + 纯黑硬阴影**（16px，0 模糊）。
- 左侧一块**略微倾斜（-2°）的米白卡片**放标题：3 行以内，总共 ≤ 5 个词，每行大写、字号 150px、字距 -0.04em；其中一个关键词放在**粉红色块**里再倾斜反方向，作为视觉重点。
- 卡片左上贴一个蓝色**小标签**（难度 / 系列名），反向倾斜 +1.5°。
- 右侧是**人像抠图位**（高度占画面 86%，贴底出血），底色用蓝色，人像朝向卡片、表情夸张。
- 右上角一个旋转 12° 的圆形**贴纸**（New! / 免费 / 2025），一个大箭头从卡片指向人像。
- 左下角黑底时长标签。

## 小尺寸测试（必做）
缩到 168×94 看：必须一眼读出标题关键词；描边、阴影不糊在一起。标题字号不要小于 120px。

## 不要
- 不要渐变、发光、真实投影、模糊；阴影一律硬阴影。
- 不要超过 5 个词的标题；不要在缩略图里放长句、网址、小字。
- 不要把人像放在正中间；不要同时有两个以上贴纸。
- 配色不要超过 4 种强色（黄 / 蓝 / 粉 / 黑），不要再加绿或紫。

## 文案口吻
行动 + 结果 + 数字（「10 分钟学会 Git」）。中文标题 4–8 字，Noto Sans SC 900，不用斜体；关键词仍放在粉红色块里。

## 用法
1. 颜色/字体只改 CSS 变量，不写死 hex。
2. 人像必须是真人抠图（透明 PNG），没有素材就保留「缺图」位并告诉用户。
3. 浏览器 1280×720 视口截图导出 PNG（< 2MB）。
