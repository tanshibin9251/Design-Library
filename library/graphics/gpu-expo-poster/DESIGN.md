# GPU Expo Poster · 显卡科技展览海报

海报 · 1080×1350（Instagram 竖版 4:5，也可等比放大做 A 系列印刷）· 风格 futuristic / dark / bold · 行业 gaming / tech / events

## 构图特征（这套的灵魂）
- **近黑底 + 一个主色**：主色用主办方 logo 的品牌色（示例是橙色），整张只有「近黑 / 白 / 灰 / 主色」。主色同时出现在显卡光圈、标题里的一个字母、数据条和网址药丸，占画面 ≤ 20%。
- **主视觉是一整张显卡的正面图**：横向占满画布宽度、居上，三风扇并排，每个风扇一圈发光的主色 RGB 环 + 暗色叶片 + 主色轮毂亮点；上缘一条主色光带；左侧银色挡板（I/O 口）、右上电源接口、下方金色 PCIe 金手指；卡的下面一团主色光晕当作「地面反光」。
- 显卡下方压两条**数据条**（左 50+ 品牌 / 右 300+ 现场整机），一左一右贴边，半透明主色底 + 上下细线。
- **宽体标题两层**：第一行「PC GAMING」小一号，第二行「EXPO」巨大，其中一个字母换成主色。字体用宽体无衬线（Unbounded 800），全大写。
- 信息区居中三行：时间 | 日期（中间一条主色竖线）→ 场地（粗）→ 地址（灰）；底部主色实心网址药丸，两端渐隐的半调圆点。
- 右上角斜光带 + 半调圆点（呼应运动海报的做法），背景有很淡的网格，中心被放射遮罩淡出。
- 左上角放**主办方 logo**（深色底请用浅色 / 白色版），右上小字「Edition 01 · 年份」。

## 不要
- 不要把显卡画成真实品牌型号或放厂商 logo；型号文字用占位。
- 不要多于一个主色；不要彩虹 RGB。
- 不要给标题加描边、渐变、投影；不要斜体。
- 不要让显卡和标题抢：显卡在上，标题在下，中间只放数据条。
- 不要在海报里放长段文字；信息区不超过 3 行。

## 文案口吻
短、硬、数字说话（50+ 品牌、300+ 现场整机）。标题 2–3 个词。中文版：标题 2–4 个字 ×2 行（如「电竞 / 装机展」），Noto Sans SC 900，中文不用斜体、字距 0；小字保留英文大写作为版面元素。

## 用法
1. 主办方 logo：把 `.org` 整块换成 `<img>`（透明 PNG，宽约 380px），颜色 `--c-primary` 换成它的品牌色，其他颜色变量保持。
2. 显卡区可保留 CSS 画的版本，也可换成真实显卡 / 展位照片（去背景、放在同一位置，保留下方光晕）。
3. 所有文案、日期、数字、网址、地址都是占位，必须换成真实内容；没有素材的位置标「缺图」。
4. 浏览器 1080×1350 视口截图导出 PNG；要出 1200×1697 的 A 系列版，把顶层 `width/height` 和各元素按 1.11 倍调整，或用 `swiss`/`gpu` 配方重新排版。
