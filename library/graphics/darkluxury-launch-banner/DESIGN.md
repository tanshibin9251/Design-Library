# Dark Luxury Launch Banner · 黑金新品发布横幅

横幅 · 1500×500（3:1，可裁成 Facebook 封面 1640×624 或网页 hero）· 风格 darkluxury / artdeco / elegant · 行业 fashion / beauty

## 构图特征（这套的灵魂）
- 近黑底，左侧有一团**极淡的暖色径向光**，不是渐变色块。
- 四周**双层细线相框**（1px，内层半透明），像请柬。
- 左侧一个**拱形（半圆顶）金线相框**放产品抠图，贴底；产品是主角，拱框里不加别的元素。
- 右侧文案块**垂直居中**：金色小字大写眼眉（字距 0.42em，前面一条细线）→ **衬线大标题**（500 字重，一个词用斜体 + 浅金）→ 一句细体说明（≤ 18 词）→ 描边按钮（无填充，末尾一条细线箭头）。
- 右上角一个品牌/编号小字。整幅只有一个金色 + 一个浅金。

## 不要
- 不要填充金色的大按钮、金属渐变、光泽、星光特效。
- 不要把产品放中间压住文案；不要给产品加投影以外的装饰。
- 不要超过两种字体；不要全部大写的标题。
- 不要用粗体（> 600）标题，奢侈感来自细和留白。

## 文案口吻
克制、感官词、数量稀缺感（「限量 700 瓶」）。不用感叹号，不写折扣。

## 中文版
标题用 Noto Serif SC 500，两行以内，不用斜体（强调词改用浅金色）；眼眉保留英文大写小字，按钮「探索」「了解更多」字距 0.3em。

## 用法
1. 颜色字体只改 CSS 变量。
2. 产品图必须是干净的透明 PNG；没有素材保留「缺图」位并告诉用户。
3. 网页 hero 用法：把 `.g-dl` 的 `width/height` 改为 `100%` / 固定高度，拱框保持固定像素。导出 PNG 用 1500×500 视口截图。
