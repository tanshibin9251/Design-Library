# Swiss Event Poster · 瑞士网格活动海报

海报 · 1200×1697（A 系列比例，印刷时按 A3/A2 等比放大）· 风格 swiss / typographic · 行业 events / arts

## 构图特征（这套的灵魂）
- 一条 6px 粗黑线从左到右，下方 4 栏等宽的**等宽字体信息表**（日期 / 时间 / 地点 / 入场），全大写，小标签半透明。
- **巨型无衬线标题**占画面上半，字距收紧（-0.045em）、行距 0.82，一行 = 一个词，中间一个词用主色。
- 一个**实心主色圆**（直径约画面宽 36%）压在右侧，里面放最重要的数字（日期）。圆是画面里唯一的圆形，其它全是直线与矩形。
- 左栏一小段无衬线导语（≤ 15 个词）+ 一个 1:1 图片位；图片位用虚线框标「缺图」。
- 底部时间表：粗线 + 三列（时间 / 项目 / 地点），行间 2px 细线。所有元素贴 72px 外边距对齐，不出现居中。
- 颜色只有三种：米白底、近黑、一个红色主色。主色占画面 ≤ 20%。

## 不要
- 不要居中对齐、不要阴影、渐变、描边文字、圆角卡片。
- 不要超过一个主色；不要再加第二个强调色。
- 不要装饰性图标和插画；图片只用一张，黑白或单色处理更好。
- 标题不要超过 3 个词；时间表不要超过 4 行。

## 文案口吻
短句、动词开头、不用感叹号。信息表用名词，不写完整句子。

## 中文版
标题换成 2–4 字 × 3 行（如「开放 / 工作室 / 之夜」），字体 fallback 用 Noto Sans SC 900；字距改为 -0.02em，行距 0.95；信息表标签保留英文小字作为网格的一部分。中文标题不要斜体。

## 用法
1. 只改 CSS 变量（`--c-primary --c-surface --c-text --c-border --f-head --f-body`），不要改 hex。
2. 替换文案，缺图位换成真实照片（裁成 1:1，去饱和）。
3. 在浏览器打开 HTML，用 1200×1697 视口截图导出 PNG；要印刷则用 PDF 导出并加 3mm 出血。
