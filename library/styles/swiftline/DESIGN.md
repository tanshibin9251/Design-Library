# Swiftline（迅捷物流）v2

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；快递、货运、仓储与第三方物流

## Feel
调度大厅：深蓝黑条、路线绿、斜体速度感。一切围绕「包裹在哪」和「要多少钱」。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#1c2b39` | 调度深蓝：顶栏、标题、计价面板、页脚 |
| Secondary | `#6b7a86` | 灰蓝：说明文字 |
| Text | `#1c2b39` | 正文 |
| Accent | `#00b894` | 路线绿：已完成节点、按钮、速度条 |
| Surface | `#f5f8fa` | 冷白 |
| Border | `#d3dde3` | 细线 |

## 字体
标题 Exo 2 800（斜体用于品牌与强调）；正文 Assistant。中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶栏深色，**运单查询框直接放在顶栏里**（输入后跳到页面里的追踪卡并滚动到位）。
2. 首屏右侧是追踪时间线：已完成（绿）/ 进行中（带光圈）/ 未到达节点，预计送达文字随单号变化。
3. 「What will it cost?」整块深蓝计价器：目的地区、重量滑块、标准 / 快速切换，实时报价。
4. 数据条四个大数字用粗顶线分隔，没有卡片。

## 不要
- 不要卡车 / 飞机 / 地球 / 箱子图标。
- 不要斜切深色首屏和橙色（旧版 / autoline-motors / fixit-home）。
- 不要夸大送达时效。
- 不要超过三个字号层级。
