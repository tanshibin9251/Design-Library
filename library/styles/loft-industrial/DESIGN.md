# Loft Industrial（工业阁楼）

> 自有原创母版，授权 ok。

- **适合**：Ecommerce；工业风家具、咖啡馆 / 办公室批量配置

## Feel
暗、重、有金属感。炭黑底、骨白字、熔橙强调，全部大写窄体标题 + 等宽小标注。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#2a2a2a` | 石墨色大块（bento 主格、深色区） |
| Secondary | `#8a8f94` | 钢灰：次要标注 |
| Text | `#ebe6db` | 骨白正文 |
| Accent | `#e0793a` | 熔橙：价格、选中、序号（每屏 ≤ 3 处） |
| Surface | `#131313` | 炭黑底 |
| Border | `#343434` | 1px 分隔线，所有格子都带框 |

## 字体
标题 Big Shoulders Display 800 全大写；正文 IBM Plex Sans；标注 IBM Plex Mono 大写加字距。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首页是 12 栏 bento 格子：1 个大标题格 + 图片格 + 数据格（25 年保修、10 天交期）+ 材质色条格 + 引言格，格与格之间 10px 缝隙。
2. 导航是顶部分栏的「表格式」菜单：每个菜单项之间有竖线，hover 整格变橙。
3. 分类页是「规格行」列表（缩略图 / 名称 / 材质 / 尺寸 / 价格），不是卡片网格。
4. 详情页是左图右「规格表」，用等宽字体与虚线分隔，选项用方形按钮。
5. 橙色滚动字带 + 页脚超大 IRONWOOD 水印字。

## 不要
- 不要圆角、不要阴影、不要渐变。
- 不要暖木色与米色（那是 oakline-furniture）。
- 不要图标卡片；用数字和大写标注代替。
- 不要用衬线字体。
