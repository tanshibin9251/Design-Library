# Renovo Studio（翻新工作室）

> 自有原创母版，授权 ok。

- **适合**：Company / Portfolio；高端住宅翻新、设计加施工

## Feel
杂志式、克制、有判断。混凝土灰底 + 墨蓝 + 砖红点缀，Playfair 斜体标题，像一本建筑期刊。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#1b2a41` | 墨蓝：页脚、深色区 |
| Secondary | `#5c677d` | 石板灰：次要文字 |
| Text | `#14181f` | 近黑 |
| Accent | `#c4553a` | 砖红：序号、悬停、强调（每屏 ≤ 2 处） |
| Surface | `#ecebe6` | 混凝土灰 |
| Border | `#cfcdc5` | 细线 |

## 字体
标题 Libre Bodoni 500（含斜体）；正文 Work Sans，小标题大写 .18em 字距。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 期刊式「刊头」：顶部一行 Issue 07 + 城市，下面 1px 黑线；首屏超大标题 + 不对称拼贴（7/5 栏图片 + 方图 + 一段引言）。
2. 作品索引：左侧 sticky 大标题「Selected work」，右侧每个案例一行（图 + 序号 + 标题 + 规格 dl 清单）。
3. 详情页用大幅「Before / After」拖动对比滑块和三栏数字（范围 / 工期 / 投资额）。
4. 「Investment guide」用三栏框线表格公开每平方英尺价格区间，不藏价。
5. 页脚超大斜体 Renovo 字标。

## 不要
- 不要北欧留白式的浅色细体（那是 nordic-interiors）；不要工程黄黑警示色（construction-pro）。
- 不要圆角、图标卡片、渐变。
- 不要把案例做成等大网格；必须有序号与规格清单。
- 不要超过一种强调色。
