# Petal Desk

> 自有原创母版，授权 ok。灵感来自一个 Femine 风格（玫瑰陶土 + 手写体）的 PHP 任务管理器，重新设计了配色、字体、导航、元素和全部图标。

- **适合**：Landing / Company；自由职业者与小型建站工作室的项目 / 任务面板、客户进度页、内部工具、SaaS 小后台的应用壳

## Feel
一张放在窗边的暖色书桌。燕麦纸底、桑椹墨色、玫瑰红的色块任务条，手写体只用来写「便条」。有秩序，但不冷。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#4a2c36` | 桑椹墨：标题、底部 Dock、「进行中」任务条、今日卡片 |
| Secondary | `#5e7d68` | 鼠尾草绿：完成态（勾选、阶段节点、完成任务条） |
| Text | `#3a2a30` | 正文 |
| Accent | `#b8525a` | 玫瑰红：按钮、待办 / 阻塞任务条、当前阶段、逾期 |
| Surface | `#f8f2eb` | 燕麦纸；四角有极淡的玫瑰 / 鼠尾草光晕 |
| Border | `#e6d6cb` | 细线、虚线 |

状态不只靠颜色：待办 = 空心圈，进行中 = 半实心圈，阻塞 = 横杠圈 + 斜纹底，完成 = 实心勾圈。白字落在 accent 上对比度 4.8:1，落在 primary 上 12:1。

## 字体
标题 **Fraunces** 600（柔和老式衬线，数字也漂亮）；正文 **Hanken Grotesk**；便条 / 日期 / 「Step N」前缀用 **Caveat** 700（只在这几处，且永不加斜体）。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体；手写体位置中文会回落到 Noto Sans SC，别用来写长句。

## 构图特征（Design signature）
1. **没有侧栏也没有顶部菜单**：顶栏只放 logo、手写日期、新建按钮和头像；四个主入口放在页面底部居中的**悬浮 Dock**（桑椹色药丸，当前页变玫瑰色，手机上只显示当前页的文字）。
2. **任务是色块手风琴**：收起时整行是实心色块（待办 / 阻塞 = 玫瑰，进行中 = 桑椹，完成 = 浅鼠尾草），展开变白底 + 玫瑰描边。阻塞行带斜纹。状态是点开的小菜单（带图标），不是原生下拉。
3. **阶段是一条「花边路径」**：每个阶段是一朵 10 瓣的花边圆章，用虚线连起来；完成的变成鼠尾草实心 + 实线，当前阶段玫瑰描边。「Step 2」用手写体、玫瑰色，写在标题前面。
4. **总览是一个圆环 + 一根分段进度条 + 四个计数**，不是四个图标药丸；首页是「本周」一周列（左侧永远是逾期列，今天是深色卡）。
5. **操作说明（how-to guide）**：每种方法一张浅玫瑰底的卡，步骤用圆形编号，截图占位是虚线框，警告是左侧玫瑰色竖线的旗帜便条。
6. 步骤清单：方块勾选框（勾上变鼠尾草绿），每行带「改名 / 删除」，全部勾完任务自动变为完成。
7. 所有图标都是 24 格自绘 SVG（1.7 描边、圆头），带一点植物感（文件夹里有一片叶子）；空状态与登录页用一枝线描植物。**没有 Emoji、没有字符图标**。

## 不要
- 不要 Emoji 或用 ✎ ✕ ❯ ⚠ 之类的字符当图标；一律用 SVG。
- 不要侧栏、不要顶部整条彩色导航条（Dock 才是导航）。
- 不要把四种状态只用颜色区分；不要原生 `<select>` 弹层。
- 不要斜体（Caveat 本身带斜势，Fraunces 没加载斜体）。
- 不要图钉、便利贴歪斜、软木板、漂浮的彩色光斑。
- 不要超过三种字体：Fraunces / Hanken Grotesk / Caveat。
- 不要在 hover 才出现的地方藏重要信息（任务操作在触屏上也要看得到）。
