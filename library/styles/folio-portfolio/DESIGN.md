# Aria Lim Portfolio（设计师作品集）

> 自有原创母版，授权 ok。

- **适合**：Portfolio；设计师、开发者、摄影师个人站

## Feel
极简、大字、作品是主角。奶油白 + 黑 + 荧光绿一点，所有信息都是一张索引表。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#111111` | 黑：全部文字与线 |
| Secondary | `#6b6b64` | 灰：序号与元信息 |
| Text | `#111111` | 黑 |
| Accent | `#b4ff3a` | 荧光绿：悬停高亮、强调词（极少） |
| Surface | `#f3f1ea` | 纸白 |
| Border | `#cfcbbf` | 细线 |

## 字体
标题 Instrument Serif（含斜体）；正文 Instrument Sans。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 导航与 logo 固定在顶部并用 mix-blend-mode:difference，在任何底色上都可见。
2. 首屏只有一个超大名字 + 一行元信息；下方是「作品索引」大号行（序号 / 标题 / 类别 / 年份），悬停行显示缩略图并轻微右移。
3. 没有卡片、没有阴影；用 1px 线和留白组织。
4. 联系页是一个巨大的邮箱链接。

## 不要
- 不要卡片网格式作品展示（那是 lens-light / bold-studio）。
- 不要渐变、圆角、图标。
- 不要超过一种强调色。
