# Pass Lab

> 自有原创母版，授权 ok。

- **适合**：Landing / Company；考证与职业培训（PMP、会计、IT 认证、雅思等）、成人在线备考平台

## Feel
成年人的学习仪表盘：板岩色、琥珀色强调、数据和进度条。认真、有结果感，不卖情怀。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#1b2733` | 板岩：标题、按钮、页脚、公告条 |
| Secondary | `#5b6b7b` | 灰蓝：说明、标签 |
| Text | `#1b2733` | 正文 |
| Accent | `#f0a202` | 琥珀：进度、高亮、仪表指针 |
| Surface | `#f5f7fa` | 冷白 |
| Border | `#d7dde4` | 细线 |

## 字体
标题 Wix Madefor Display 800；正文 Wix Madefor Text。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶部有一条深色公告条（下期开班 / 剩余名额），下面是普通导航，主 CTA 是「Free practice test」。
2. 首屏右侧是一块「仪表盘」：半圆准备度仪表（72%）、三个小数据格，数字有进度动画。
3. 考试类别是带通过率进度条的卡片，每张写首次通过率与建议周数。
4. 模拟测验：一次一题、倒计时、答完立刻显示正确选项与解析，最后出得分与建议。
5. 学习计划器：两个滑块（周数、每周小时数），实时拆成 学习 / 练习 / 模考 三段比例条。

## 不要
- 不要卡通、插画、Emoji、证书奖杯装饰。
- 不要渐变色大色块；只用纯色。
- 不要夸张的「保证通过」红色字；文案保持克制。
- 不要超过三个字号层级。
