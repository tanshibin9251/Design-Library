# Tuina Heritage（推拿传承）

> 自有原创母版，授权 ok。

- **适合**：Company；中医推拿、拔罐艾灸、理疗，强调传承与注册资质

## Feel
庄严、对称、有传承感。朱红 + 墨黑 + 黄铜金，装饰艺术（Art Deco）的阶梯切角与双线框。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#a52a1d` | 朱红：首屏、印章、深色区 |
| Secondary | `#6d5a3a` | 旧黄铜棕：次要文字 |
| Text | `#1d1814` | 墨黑 |
| Accent | `#c9a04a` | 黄铜金：线框、汉字、按钮 |
| Surface | `#f6eedd` | 宣纸米色 |
| Border | `#ddd0b0` | 浅金线 |

## 字体
标题 Limelight（Art Deco 展示体，全大写）；正文 Nunito Sans。汉字用 Noto Serif SC。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶部黑色信息条（营业时间 + 注册号），下面三栏对称导航，中间是红色印章 + 字标；底部是金色双线（3px double）。
2. 首屏整块朱红，背景是金色放射线（conic-gradient），右侧超大竖排汉字「推拿」半透明做水印，图片被切成 Art Deco 阶梯拱形。
3. 疗法与病症用双线金框「汉字卡」（推 / 灸 / 拔 / 刮、頸 / 腰 / 眠…），不是图标。
4. 师傅介绍：金色细框 + 三个大数字（32 年 / 40k 次 / 注册编号）。
5. 「体质测试」是单题卡片式问卷，选项带选中态；价格表用双线顶部。

## 不要
- 不要手绘风、莲花（thai-touch）；不要日式竖排导航（reflex-point）。
- 不要圆角、阴影、渐变（放射线除外）。
- 不要用库存「石头 + 竹子」图；汉字就是主视觉。
- 不要超过两种强调色（红 + 金）。
