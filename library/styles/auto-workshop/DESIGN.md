# Torque Garage（扭矩车厂）

> 自有原创母版，授权 ok。

- **适合**：Company；汽车维修、保养、洗车

## Feel
工单感、可信、不玩虚的。石墨蓝 + 安全黄，车牌输入和进度追踪是核心。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#1f2f46` | 石墨蓝：首屏、按钮 |
| Secondary | `#5b6676` | 钢灰：次要文字 |
| Text | `#14181f` | 近黑 |
| Accent | `#ffc400` | 安全黄：高亮、状态、边线 |
| Surface | `#f4f5f6` | 工厂灰白 |
| Border | `#cfd3d8` | 分隔线 |

## 字体
标题 Rubik 700 全大写；正文 Roboto Condensed。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶部黑色信息条（营业时间 + 免费接送），导航底边 4px 安全黄粗线。
2. 首屏右侧是「车牌输入」卡：马来西亚车牌样式（MY + 黄底车牌字），输入后进入进度页。
3. 服务六宫格用 2px 黑线网格表格，不是圆角卡片；价格明码标价。
4. 套餐页先选车型（Compact / Sedan / SUV）再看价格。
5. 「Track」页是工单时间线：已完成 / 进行中（黄色光环）/ 待办。

## 不要
- 不要深色炫酷汽车摄影风（那是 autoline-motors）。
- 不要圆角与渐变。
- 不要隐藏价格。
