# Rumah Singgah（归栖民宿）

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；民宿、短租、度假屋

## Feel
温暖、可信、像在朋友家做客。棕榈绿 + 沙色，大图首屏 + 浮动搜索条。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#4d7c0f` | 棕榈绿：按钮、选中日期 |
| Secondary | `#8a6d3b` | 藤编棕：次要文字 |
| Text | `#24231b` | 深橄榄黑 |
| Accent | `#f59e0b` | 琥珀黄：星级、高亮 |
| Surface | `#faf6ea` | 沙色底 |
| Border | `#e6dec7` | 浅沙线 |

## 字体
标题 Spectral 600；正文 Be Vietnam Pro。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏是全幅照片，底部渐变，搜索条悬浮在左下（地点 / 入住 / 退房 / 人数 / 搜索）。
2. 房源卡：4:3 圆角图 + 评分 + 地点 + 设施胶囊 + 每晚价格；筛选用胶囊。
3. 详情页：1 大 + 4 小的相册马赛克，右侧粘性预订卡。
4. 可订日期是真日历格：已订划线、你选的日期深色。

## 不要
- 不要深色背景。
- 不要电商式商品卡（价格在最右上）。
- 不要通篇图标；用设施胶囊文字。
