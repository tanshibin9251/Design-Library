# Pawsh（宠物精品店）

> 自有原创母版，授权 ok。

- **适合**：Ecommerce / Company；宠物用品、宠物美容、精品店

## Feel
精致、轻奢、像高端宠物买手店。深墨绿 + 杏橙，Familjen Grotesk 紧字距。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#1f3d36` | 深墨绿：首屏、按钮文字 |
| Secondary | `#6b7b73` | 灰绿：次要文字 |
| Text | `#16211e` | 近黑 |
| Accent | `#f59e5b` | 杏橙：圆章、价格、高亮 |
| Surface | `#fbf8f3` | 奶白 |
| Border | `#e4ddd2` | 细线 |

## 字体
标题 Familjen Grotesk 700（紧字距 -.04em）；正文 Hind。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶部黑色窄公告条 + 三栏居中 logo 导航（左：商店，中：paw+sh，右：日志 / 访问 / 购物袋）。
2. 首屏深绿，宠物图被裁成圆形加杏橙描边，旁边旋转的圆章「First groom -20%」。
3. 分类入口是圆形图（5 个），悬停描边变橙并上浮。
4. 美容服务按体型分档的表格式卡（Small / Medium / Large），不是图标列表。

## 不要
- 不要手绘与可爱爪印（那是 happy-paws）。
- 不要暖色大面积；以深绿为主。
- 不要卡通字体。
