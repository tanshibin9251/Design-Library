# Hanabi Matsuri（花火祭）

> 自有原创母版，授权 ok。

- **适合**：Landing；社区夏祭、花火大会、市集 / 展会式的一夜活动

## Feel
夏夜祭典：灯笼、屋台、花火和一点喧闹。深紫夜色上有大红灯笼和黄色烟花，边框粗、颜色亮、字很大，像贴在镇上的海报。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#2a1b3d` | 夜空紫：夜色背景块、粗描边、页脚 |
| Secondary | `#f5b623` | 烟花黄：标题、倒计时、选中态 |
| Text | `#2a1b3d` | 正文 |
| Accent | `#e0312f` | 灯笼红：灯笼、按钮、序号、美食摊 |
| Surface | `#fff6e2` | 和纸奶油色 |
| Border | `#2a1b3d` | 3px 粗描边 |

## 字体
标题 Dela Gothic One（粗圆体，海报感）；正文 Kiwi Maru（圆润明朝）。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 导航是「一排挂在绳上的灯笼」：每个灯笼是一个链接，里面竖排汉字（番組 / 屋台 / 花火 / 切符 / 道順），下方英文；会缓慢摆动，悬停放大。
2. 首屏是深紫夜空，CSS 画的烟花环依次绽放；超大「花火祭」黄字带红色描边与硬投影；倒计时每秒走，自动指向下一个 8 月 15 日 20:00；底边斜切成 V 形。
3. 屋台地图是 6×3 方格，按类别着色（食 / 游戏 / 店），点击后右侧卡片显示内容和价格。
4. 切票做成撕票根的样子（两侧缺口 + 虚线 + 编号）。
5. 节目表是粗线时间轴：大号时刻、圆点、节目名。

## 不要
- 不要加樱花、富士山、艺伎、鸟居。
- 不要用暗金、黑金的高级感（tsukimi-ryokan / gilded-ledger）。
- 不要渐变色块背景（灯笼内的径向渐变除外）、不要毛玻璃。
- 不要加图标、Emoji。
- 不要超过三个字号层级。
