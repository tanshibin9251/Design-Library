# Baoshan Herbal Clinic（保善堂中医诊所）

> 自有原创母版，授权 ok。

- **适合**：Company；中医诊所、药材行、推拿理疗

## Feel
沉稳、双语优先、有「药柜」意象。青瓷绿 + 树皮棕 + 朱砂，汉字大而清晰。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#2f6f5e` | 青瓷绿：标题、按钮、页脚 |
| Secondary | `#8b6b4a` | 树皮棕：药柜、次要文字 |
| Text | `#1f2a26` | 墨绿黑 |
| Accent | `#b83a2a` | 朱砂红：序号、悬停高亮 |
| Surface | `#f6f4ec` | 宣纸米 |
| Border | `#d9d6c6` | 细线 |

## 字体
标题 Noto Serif SC 700；正文 Noto Sans SC。所有主要标签中英并列。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏右侧是一个 5×4 的「药柜」：每个抽屉是一味药材汉字，悬停时抽屉抽出并变朱红。
2. 「四诊」流程用 望 / 闻 / 问 / 切 四个大字表格，不用图标。
3. 病症用一字入口（眠 / 痛 / 胃…）的小卡片。
4. 医师用 4:5 肖像，名字中英并列。
5. 预约表单字段中英对照。

## 不要
- 不要绿色叶子 / 莲花 / 太极库存图。
- 不要现代 SaaS 渐变。
- 不要英文标题大于中文标题。
