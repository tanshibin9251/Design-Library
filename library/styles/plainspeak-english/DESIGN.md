# Plainspeak English

> 自有原创母版，授权 ok。

- **适合**：Landing / Company；在线英语（或任何外语）课程平台、语言学校、家教平台

## Feel
瑞士国际主义版式：12 栏网格、粗黑线、巨大无衬线字、一点信号红。清楚、不啰嗦，像一本语言教材的封面。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#111111` | 黑：标题、粗线、按钮、页脚 |
| Secondary | `#6b6b6b` | 灰：说明 |
| Text | `#1a1a1a` | 正文 |
| Accent | `#e10600` | 信号红：序号、重点词的句号、按钮悬停 |
| Surface | `#f4f4f0` | 微暖白 |
| Border | `#cfcfc8` | 细线 |

## 字体
标题 Schibsted Grotesk 800（字距 -.04em，行高 .88）；正文 Public Sans。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶栏是 12 栏网格：左 logo，中间带编号（01 02 03）的菜单，右侧 Log in / Start free；上沿 6px 黑线。
2. 首屏只有一个巨大标题「Say it plainly.」，句号用红色；下面一行四个数据，用竖线分隔。
3. 课程是「表格行」而不是卡片：序号 · 课名 · 级别（CEFR 框）· 时长 · 价格 · 箭头，悬停整行反白。
4. Level check 页：一次一题、顶部分段进度、结束出巨大的 CEFR 等级（A1–C1）和课程建议。
5. 页脚是整块黑底 + 巨型 wordmark。

## 不要
- 不要圆角、阴影、渐变、插画、Emoji。
- 不要多于一个强调色（只有红）。
- 不要居中对齐的大段正文；全部左对齐网格。
- 不要超过三个字号层级（巨标题 / 小标题 / 正文）。
