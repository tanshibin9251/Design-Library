# Quiet Grace（静恩社区）v2

> 自有原创母版，授权 ok。

- **适合**：Company / Blog；教会、社区团体、互助组织、非营利小组织的聚会与服务站

## Feel
社区公告板：纸张、图钉、一周的节奏。温暖、可读、没有宗教符号堆叠，欢迎第一次来的人。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#38536b` | 石板蓝：标题、按钮、星期卡（当天聚会）、页脚 |
| Secondary | `#8aa0b3` | 灰蓝：标签、便签底色 |
| Text | `#2b3440` | 正文 |
| Accent | `#e0a458` | 蜜糖黄：图钉、下划线、今日描边 |
| Surface | `#fbf6ee` | 奶油纸 |
| Border | `#e3d9c6` | 细线 |

## 字体
标题 Lora 600；正文 Nunito Sans。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 最上是一条深蓝公告条（下次聚会时间 + 「Plan a visit」），顶栏是左对齐的文字 logo + 带下划线的链接，没有图标。
2. 首屏右侧是一张「聚会流程单」卡片：上缘一条黄线，下面一列时间 + 环节（点线分隔），像打印出来的节目单。
3. 「一周节奏」是 7 列星期卡，有聚会的当天用深蓝底，今天（按浏览器日期）加黄色外描边。
4. 公告板：瀑布流便签，略微旋转，每张顶部一颗黄色图钉，底色为奶油 / 浅黄 / 浅蓝。
5. 「祷告 / 求助 / 参与」三栏，用上下粗线和竖线隔开。

## 不要
- 不要朱红点睛、竖排大标题、留白过度的日式极简（旧版 / reflex-point）。
- 不要十字架、鸽子、手合十剪影和库存图。
- 不要深色模式。
- 不要超过三个字号层级。
