# Kissa Maruyo（喫茶まるよ）

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；昭和风格的日式喫茶店、复古咖啡馆、烘焙豆小店

## Feel
昭和喫茶：遮阳篷、搪瓷招牌、手写菜单板、奶油苏打。暖纸色底 + 咖啡棕 + 一点苏打绿，亲切、略显旧，但不脏。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#4a2a1a` | 咖啡棕：标题、双线框、按钮、页脚 |
| Secondary | `#b8873a` | 琥珀：小字、点线 |
| Text | `#3a2418` | 正文 |
| Accent | `#2f8f78` | 苏打绿：遮阳篷、标签、价格 |
| Surface | `#f7eed8` | 旧纸色 |
| Border | `#dcc9a0` | 淡线 |

## 字体
标题 Kaisei Decol（带装饰的昭和明朝，字距 .08em+）；正文 M PLUS Rounded 1c。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 页面最上方是绿 / 米色条纹遮阳篷，下沿是一排扇贝形垂边；其下是搪瓷招牌式 logo（3px 双线圆角框）。
2. 导航是胶囊标签，不是文字链接；右侧「営業中 / 準備中 / 定休日」小牌子按当前时间自动翻转。
3. 首屏左边是「菜单板」：双线框，品名—点线—价格，右上角贴一枚旋转的圆形贴纸；板里有「本日のおすすめ」按星期几自动换。
4. 所有卡片是 3px 实线 + 大圆角 + 偏移色影（hard shadow），按钮同样；没有渐变、没有模糊阴影。
5. 价目一律用点线引导（dotted leader），菜单页两栏。

## 不要
- 不要竖排大标题、侧栏、青海波（已被其他日式模板用掉）。
- 不要深色模式、不要玻璃拟态、不要高级咖啡馆的极简风。
- 不要加图标、Emoji。
- 不要库存图堆叠咖啡豆特写。
- 不要超过三个字号层级。
