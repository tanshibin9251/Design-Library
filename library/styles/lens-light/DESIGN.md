# Lens & Light（镜头与光）v2

> 自有原创母版，授权 ok。

- **适合**：Portfolio；摄影师作品集、婚礼 / 人像 / 编辑摄影工作室、影像艺术家

## Feel
一张暗房里的接触印相纸：黑色边框里排着编号的底片格，鼠标移上去才显色。信息像 EXIF，一行一行。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#151413` | 底片黑：标题、底片条背景、按钮、页脚 |
| Secondary | `#8c877b` | 暖灰：编号、说明 |
| Text | `#24221f` | 正文 |
| Accent | `#d6322a` | 安全灯红：选中标记、EXIF 数值、悬停 |
| Surface | `#f1efe9` | 相纸白 |
| Border | `#d4d0c5` | 细线 |

## 字体
标题与界面 DM Mono 500（等宽，像镜头标注）；正文 Albert Sans。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏是一张「接触印相纸」：黑底、6 列底片格、每格带编号 01–10；格子默认黑白，悬停 / 聚焦才还原彩色并轻微放大；有竖幅（跨 2 行）和横幅（跨 2 列）。
2. 点选一格：下方「大图 + EXIF 面板」同步显示该帧，右侧列出 Frame / Focal length / Aperture / Shutter / Sensitivity，红色圆圈标记选中格。
3. 顶栏三栏：左坐标、居中 logo、右菜单，全部使用等宽大写小字，没有色块。
4. 服务三栏用竖线分隔，编号 + 大写标题，不用卡片。
5. 页脚黑色块。

## 不要
- 不要全黑背景 + 白色细衬线（旧版）；这里是相纸白 + 黑色底片条。
- 不要全屏轮播、视差、淡入淡出幻灯。
- 不要给照片加边框阴影或圆角。
- 不要超过三个字号层级。
