# Verde & Co. Chartered Accountants（会计师事务所）

> 自有原创母版，授权 ok。

- **适合**：Company；会计、税务、审计、秘书服务

## Feel
可信、数字清晰、不花哨。墨绿 + 铜金 + 纸白，一张账本卡片当主视觉。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#14532d` | 墨绿：标题、按钮、页脚 |
| Secondary | `#6b6b5a` | 灰橄榄：次要文字 |
| Text | `#1c1f1c` | 近黑 |
| Accent | `#b45309` | 铜棕：强调、标签 |
| Surface | `#fbfaf5` | 账簿纸白 |
| Border | `#dad8c9` | 账本线 |

## 字体
标题 Literata 600；正文 Public Sans；数字用 tabular-nums。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏右侧是「账本」卡片：虚线分行、右对齐数字、底行高亮「Filed on time ✓」，有柔和的偏移阴影。
2. 服务三栏用顶部 3px 粗线 + 条目表，不是图标卡片。
3. 「税务日历」是首页就能看到的清单（日期 / 事项 / 类别标签），逾期风险用实心标签。
4. 团队用方形肖像；套餐明码标价（月费）。

## 不要
- 不要深蓝企业风（那是 enterprise-blue / lexington-law）。
- 不要股票图（握手、笔记本）。
- 不要图标；用数字与表格。
