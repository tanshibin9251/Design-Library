# Ironbridge Build（铁桥建造）v2

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；承建商、设计与施工一体公司、翻新与工程服务商

## Feel
工地办公室的墙：水泥灰、安全黄、粗黑线、斜纹警示带。像一张贴出来的进度表。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#2f3437` | 混凝土黑灰：标题、粗线、条形、页脚 |
| Secondary | `#8a9099` | 钢灰：说明、月份刻度 |
| Text | `#25282a` | 正文 |
| Accent | `#f5a300` | 安全琥珀：高亮词、斜纹带、阶段条 |
| Surface | `#eceae5` | 灰泥色 |
| Border | `#c9c6bd` | 细线 |

## 字体
标题 Roboto Slab 700（大写）；正文 Roboto。中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶部一条 12px 琥珀 / 灰黑 45° 警示斜纹带；logo 是安全帽拱形。
2. 首屏右侧是「进度表 + 预算」：12 个月刻度、六个阶段条（设计审批→移交），选建筑类型、拖面积、选档次，条形长度与总工期（6–12 个月）随之变化，并给出估算造价。
3. 数据条是四个大数字，3px 粗线隔开（项目数、准时率、工伤、质保）。
4. 所有按钮和块都是方角 3px 描边。

## 不要
- 不要黑黄斜切全屏首图 + 安全帽 / 吊车库存图（旧版）。
- 不要深蓝橙色配色（旧版 / fixit-home）。
- 不要夸大「最低价」。
- 不要超过三个字号层级。
