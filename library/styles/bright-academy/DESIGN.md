# Bright Academy（明亮学堂）v2

> 自有原创母版，授权 ok。

- **适合**：Landing / Company；补习中心、少儿教育机构、技能培训班

## Feel
一本做满笔记的练习册：石墨色、荧光青柠色高亮，粗描边、折页标签式导航，一切像学生在课桌上排课表。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#1f2933` | 石墨：标题、描边、深色格 |
| Secondary | `#d9f0a0` | 淡青柠：科目格、点缀 |
| Text | `#1f2933` | 正文 |
| Accent | `#b7e04b` | 青柠：荧光笔下划线、高亮、按钮悬停 |
| Surface | `#f7f9f2` | 米白 |
| Border | `#dfe5d2` | 虚线 |

## 字体
标题 Space Grotesk 700；正文 DM Sans。中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶栏下方 3px 粗线；导航项是「文件夹标签」（顶角圆、悬停淡青柠），最右标签为深色「Free trial class」。
2. 首屏右侧是可以动手排的「周课表」：先选科目，再点格子放入；格子随科目换色，顶部实时显示「几节课 / 每月多少钱」。
3. 「家长每月看到什么」：一页式成绩 + 态度横条报告。
4. 卡片 3px 石墨描边 + 青柠硬投影，不使用渐变。

## 不要
- 不要蓝黄儿童风、云朵、铅笔图标（tuition-centre）。
- 不要夸大「保证提分」的文案。
- 不要超过三个字号层级。
