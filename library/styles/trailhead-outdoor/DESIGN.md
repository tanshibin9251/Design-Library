# Trailhead Outdoor（山径户外）

> 自有原创母版，授权 ok。

- **适合**：Ecommerce；户外、露营、攀岩、登山装备零售与租借

## Feel
踏实、有地形感。森林绿 + 岩石棕 + 警示橙，纸色底，全幅山景照片。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#2f4a3a` | 森林绿：导航按钮、页脚、规格数字 |
| Secondary | `#8a6f4e` | 岩石棕：攀岩 / 次要点缀 |
| Text | `#25291f` | 深橄榄黑 |
| Accent | `#d8742a` | 营火橙：CTA、难度点、警示 |
| Surface | `#f1ede2` | 地图纸色 |
| Border | `#cfc7b3` | 等高线与描边 |

## 字体
标题 Bitter 700（粗衬线）；正文 Source Sans 3。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶部深绿「路况播报条」，首屏右下角是实时路况小卡（Dry / Wet / Flow）。
2. 导航不是品类，而是活动：Hike / Camp / Climb / Paddle，每项前有彩色小点。
3. 全幅山景首屏 + 底部渐变压深；活动入口是 3:4 的竖版全幅照片卡。
4. 商品卡显示重量 / 容量 / 防水数据三个徽章；难度用 4 个圆点表示。
5. 「Gear planner」：选活动 / 天数 / 环境，生成装备清单；每个商品还有「租借」入口。

## 不要
- 不要运动品牌式的斜体粗黑字（那是 sprint-gear）。
- 不要深色科技风（那是 peak-performance）。
- 不要纯白底；底色必须是纸色，带等高线花纹。
- 不要在商品图上叠价格牌。
