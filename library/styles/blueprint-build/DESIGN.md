# Blueprint Build（蓝图营造）

> 自有原创母版，授权 ok。

- **适合**：Company；装修施工、商业 fit-out，强调专业与进度

## Feel
制图感、精确、像一张 A1 施工图。蓝图底色 + 白色细线 + 薄荷绿标注，所有内容放在带边框的图纸上。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#14407f` | 蓝图深蓝：卡片、深色区 |
| Secondary | `#8fb4ea` | 浅蓝：次要文字 |
| Text | `#e8f1ff` | 图纸白线与文字 |
| Accent | `#6ef2c8` | 薄荷绿：标注线、数字、按钮（每屏 ≤ 3 处） |
| Surface | `#0c2d62` | 蓝图底色 |
| Border | `#2d5aa0` | 网格线 |

## 字体
标题与标注 JetBrains Mono（大写 + 字距）；正文 Barlow。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 页面是一张「图纸」：全站背景有 100px / 20px 的网格，主内容在双线边框内，右上角是图签 DWG NO. / SCALE。
2. 首屏右侧是 SVG 线稿户型图，带尺寸线、虚线剖线和「REMOVE WALL」标注。
3. 「施工进度表」是真正的甘特图（12 周 × 阶段），不是图标步骤。
4. 项目列表是「项目登记册」表格（编号 / 项目 / 类型 / 面积 / 工期 / 状态）；有快速估价页（滑杆）。
5. 每个区块都有「Sheet 02 · Scope」式的编号标签。

## 不要
- 不要照片大图叠字（用线稿与表格）。
- 不要圆角、阴影、渐变。
- 不要暖色；不要黄黑工程警示色（construction-pro）。
- 不要图标；用编号和线稿。
