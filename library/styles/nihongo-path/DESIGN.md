# Nihongo Path（にほんごパス）

> 自有原创母版，授权 ok。

- **适合**：Landing / Company；面向外国人 / 初学者的日语学习平台、APP 官网、语言学校的在线课程站

## Feel
轻松、鼓起来的、像贴纸。粉红 + 薄荷 + 黄色，圆鼓鼓的卡片，假名当图形。学日语的第一天就不吓人。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#c2386b` | 樱桃粉：标题、主按钮、页脚 |
| Secondary | `#6cc6b4` | 薄荷：标签、已完成节点、色块 |
| Text | `#3a2230` | 正文 |
| Accent | `#ffb703` | 蛋黄：当前节点、强调按钮、高亮 |
| Surface | `#fff6f1` | 奶油粉 |
| Border | `#f1d9cf` | 点线 |

## 字体
标题 Mochiy Pop One（圆润波普）；正文 Zen Kaku Gothic Antique。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶栏是悬浮胶囊：左侧圆形「あ」徽标，右侧胶囊式链接，投影柔和，页面滚动时一直悬浮。
2. 首屏标题里的「ちょっとずつ」下面是黄色荧光笔划线；右侧是一组略微旋转的假名方块。背景有两团大色块（blob）。
3. 学习路径：S 形弯曲的虚线路，九个圆形节点（已完成 / 当前 / 未开始），点击节点右侧泡泡显示该单元内容。
4. 假名练习：46 格五十音表，点一格显示罗马音；旁边是 4 选 1 的测验和积分。
5. 页脚是大圆角的深粉色块，从底部"升"起。

## 不要
- 不要硬边描边、偏移硬阴影（kissa-showa / ippon-dojo 已用）；用柔和模糊阴影。
- 不要竖排首屏标题、和风纹样、鸟居、樱花飘落。
- 不要深色模式。
- 不要超过三个字号层级。
