# Daily Table

> 自有原创母版，授权 ok。

- **适合**：Blog / Company；家常菜综合食谱站、每周菜单规划、家庭饮食博客

## Feel
一周的餐桌计划表：茄子紫的墨色、番茄红的重点、奶油纸。实用、有条理，不装饰。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#3a2745` | 茄子紫：标题、按钮、公告条、页脚 |
| Secondary | `#7a5a8a` | 淡紫：说明、小标 |
| Text | `#2e2433` | 正文 |
| Accent | `#d8472b` | 番茄红：「今天」、序号、CTA |
| Surface | `#fffaf0` | 米白 |
| Border | `#e6dccb` | 细线 |

## 字体
标题 Alegreya 700（书写感衬线，有食谱书气质）；正文 Alegreya Sans。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏下方是「一周板」：7 列星期，每列一道晚餐名与时长，当天用红框高亮。
2. 食谱列表是横向条目：左边小方图 + 标题 / 食材 / 标签 + 右边大号分钟数；悬停整行右移；左侧竖栏筛选（时间、饮食）。
3. 周计划器：7 个下拉选晚餐，右侧「购物清单」自动合并同类食材并标注「for N dinners」，选择存在浏览器里。
4. 食谱详情的步骤编号是红色大号数字，不是圆圈。
5. 顶部有一条深紫公告条（Free weekly meal plan），导航下划线风格，而不是胶囊。

## 不要
- 不要手绘、贴纸、胶带（washoku-note）；不要粉彩点阵（sugar-and-crumb）；不要圆形盘子缩略图（wok-and-steam）。
- 不要渐变、阴影（仅下拉菜单有一圈轻影）。
- 不要加图标、Emoji。
- 不要超过三个字号层级。
