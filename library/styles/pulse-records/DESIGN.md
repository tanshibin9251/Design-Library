# Pulse Records（脉冲唱片）v2

> 自有原创母版，授权 ok。

- **适合**：Portfolio / Ecommerce；独立唱片厂牌、黑胶店、音乐人品牌站、演出与周边商店

## Feel
唱片行的木箱和柜台：钴蓝、粉红、黄油黄，硬投影，价格贴纸。不安静，但很清楚。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#1a35d6` | 钴蓝：顶栏、主按钮、选中曲目 |
| Secondary | `#ff6f91` | 粉红：副色、封面色块、深色块阴影 |
| Text | `#101323` | 墨黑：正文、粗线、页脚 |
| Accent | `#ffd23f` | 黄油黄：贴纸、悬停、跑马灯 |
| Surface | `#f4efe6` | 封套纸色 |
| Border | `#101323` | 3px 粗描边 |

封面里的蓝 / 粉 / 黄 / 黑色块是内容数据色，仅用于专辑封面占位。

## 字体
标题 Rubik Mono One（超宽单体）；正文 Chivo 600。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶栏钴蓝，左上 logo 是一张会转的小黑胶；顶栏下一条黄色跑马灯（New press · Limited 300 …）。
2. 首屏右侧是一台「唱机」：黑底卡片 + 粉色硬投影，CSS 画的黑胶唱片（沟纹、标签、反光）会随「▶ Spin」转动，唱臂落下；可切换 33 / 45 RPM；点右下曲目列表换「Now spinning」标题。
3. 「The crate」：横向滚动的唱片箱，唱片套为 3px 黑框 + 硬阴影，右上角圆形黄色价格贴纸，悬停略旋转；scroll-snap。
4. 「New this week」是目录编号行（PUL-041 · 艺人 · 标题 · 格式 · 价格），悬停整行变黄。
5. 页脚黑色，标题黄色。

## 不要
- 不要黑白复古宣传画、霓虹发光（旧版 / neon-nexus）。
- 不要唱片 / 耳机 / 音符图标。
- 不要柔和阴影、渐变背景；只用硬投影与纯色。
- 不要超过三个字号层级。
