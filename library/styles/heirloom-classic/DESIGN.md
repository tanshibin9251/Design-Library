# Heirloom Classic（传世古典）

> 自有原创母版，授权 ok。

- **适合**：Company / Ecommerce；红木、柚木、定制与古典家具，修复服务

## Feel
庄重、对称、有纸质感。深酒红 + 古铜金 + 象牙白，全部居中对称。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#4a1c24` | 酒红：深色区块、顶部公告、hover |
| Secondary | `#7a6a52` | 旧铜灰：次要文字 |
| Text | `#2a1e1a` | 深褐正文 |
| Accent | `#a8803a` | 古铜金：边框、罗马数字、小标题 |
| Surface | `#f8f3e8` | 象牙白底 |
| Border | `#d9ccb0` | 细线 |

## 字体
标题 Newsreader 400（含斜体）；正文 Jost，小标题大写加 .3em 字距。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 三栏导航：左右各 3 个大写字距菜单，品牌字标居中，下方一行「Furniture Makers · Est. 1962」。
2. 首屏是一个双线金框（外框 + 内缩 9px 的内框），上下边框中间各有一个 ❖ 装饰。
3. 集合用罗马数字 I / II / III 的三栏竖线格；步骤也用罗马数字。
4. 核心转化是「Request a quotation」而不是购物车，没有价格筛选与加购。
5. 商品详情页用 dl 定义列表（木材 / 尺寸 / 榫接 / 表面 / 工期）。

## 不要
- 不要购物车、折扣标签、倒数计时。
- 不要无衬线大标题；标题必须是 Cormorant。
- 不要不对称的杂志式排版（那是 editorial 风格）。
- 不要超过一种强调色（金）。
