# Curve Modern（圆润现代）

> 自有原创母版，授权 ok。

- **适合**：Ecommerce；年轻化家具、软装、小户型

## Feel
圆、软、颜色吵闹但干净。黑色 2px 描边 + 硬阴影，像贴纸一样。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#e4572e` | 珊瑚红：主按钮、Bag 胶囊 |
| Secondary | `#3a6ea5` | 钢蓝：测验大卡、贴纸 |
| Text | `#1c1b22` | 近黑：文字与所有描边 |
| Accent | `#ffc83d` | 奶油黄：高亮词、hover |
| Surface | `#fff7ec` | 暖白底 |
| Border | `#1c1b22` | 描边与文字同色 |

## 字体
标题 Plus Jakarta Sans 800，字距 -.04em；正文 DM Sans。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 导航是悬浮的胶囊（圆角 99px + 2px 黑描边 + 硬投影），不是通栏。
2. 首屏居中超大标题，其中一个词有黄色倾斜底；背景是大色块圆，产品图片倾斜浮在下方，右侧有旋转贴纸。
3. 黑底倾斜 -1.2° 的滚动字带分隔区块。
4. 分类用「大色块卡」而不是图片卡；商品放在彩色圆顶舞台里，右下一个圆形 + 号。
5. 颜色测验是整页的核心转化入口；手机端底部有悬浮的胶囊导航。

## 不要
- 不要细线条、不要阴影柔化（只用硬投影）。
- 不要米色 / 木色（那是 oakline）；不要黑色大块（那是 loft）。
- 不要直角；最小圆角也要 24px。
- 不要超过 4 种色块同屏。
