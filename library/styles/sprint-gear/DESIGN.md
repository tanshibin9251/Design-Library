# Sprint Gear（冲刺装备）

> 自有原创母版，授权 ok。

- **适合**：Ecommerce；跑鞋、球类、训练服饰、限量发售

## Feel
快、吵、粗。体育场荧光黄 + 纯黑 + 警示红，全部斜体大写。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#0d0d0d` | 纯黑：描边、深色区、按钮 |
| Secondary | `#ff3b2f` | 警示红：贴纸、价格牌、投影 |
| Text | `#0d0d0d` | 纯黑正文 |
| Accent | `#d9ff1f` | 荧光黄：首屏底色、字带、选中 |
| Surface | `#ffffff` | 纯白 |
| Border | `#0d0d0d` | 3px 黑描边 |

## 字体
标题 Bebas Neue（斜体、全大写）；正文 Archivo。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶部荧光黄字带 + 3px 黑线；导航按钮整体 skew(-8deg)，logo 是黑底黄字斜体块。
2. 首屏整块荧光黄，超大斜体标题，其中一行只有描边；右侧产品抠图旋转 -6° 加 12px 硬投影，右上有爆炸星形贴纸。
3. 左侧竖排文字轨（NEW IN）+ 横向吸附滚动的商品卡，价格是旋转的黑底价格牌。
4. 「Drop」倒计时区块：黑底，黄色大数字格。
5. 详情页右侧是 sticky 购买卡（3px 黑框 + 10px 硬投影），尺码是 6 列方块。

## 不要
- 不要圆角、不要渐变、不要柔和阴影。
- 不要出现衬线字体或细体。
- 不要米色/木色/大地色（那是别的模板）。
- 不要超过 3 种颜色（黑、黄、红）。
