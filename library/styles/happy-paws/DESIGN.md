# Happy Paws（欢乐爪爪）v2

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；宠物诊所、美容、宠物用品店、领养中心

## Feel
暖和、爱热闹的宠物店：丹宁蓝加珊瑚橙，圆角很大，一切像贴在冰箱上的拍立得。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#2f4b7c` | 丹宁蓝：标题、粗描边、深色块 |
| Secondary | `#8ad0c7` | 薄荷水色：标签、中间卡片 |
| Text | `#26334d` | 正文 |
| Accent | `#ff8a5b` | 珊瑚橙：按钮、选中、重点词 |
| Surface | `#f4f9ff` | 浅天空白 |
| Border | `#d5e3f2` | 点线 |

## 字体
标题 Sniglet 800（圆润憨厚）；正文 Varela Round。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏右侧是 4 张略微倾斜的「拍立得」宠物卡（名字、年龄、性格标签），悬停扶正并上浮——领养 / 日常宠物墙。
2. 顶栏有 3px 点线底边，logo 是向左歪的「爪印」水滴形徽章，右侧「Book a visit」是深色胶囊。
3. 护理方案三张卡：粗描边 + 大圆角，中间一张薄荷色并略下移。
4. 「宠物年龄换算」整块深蓝圆角横幅：选动物类型、拖年龄，输出等效人类年龄和对应护理阶段说明。
5. 页脚是大圆角顶的深蓝块。

## 不要
- 不要手绘线稿、爪印图标、骨头 / 猫爪 Emoji。
- 不要橙+蓝绿旧配色（旧版）；不要 Fraunces。
- 不要硬投影方块（kissa-showa / ippon-dojo 用过）：这里只用底部 5px 描边的按钮。
- 不要超过三个字号层级。
