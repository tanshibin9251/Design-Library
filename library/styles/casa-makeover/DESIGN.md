# Casa Makeover（居家焕新）

> 自有原创母版，授权 ok。

- **适合**：Company；面向年轻业主的住家翻新，套餐 + 预算计算器

## Feel
友好、轻快、让人放心。奶油底 + 紫罗兰 + 粉 + 薄荷，圆角胶囊和波浪分隔，价格全部公开。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#6c4ad9` | 紫罗兰：按钮、标题强调、高亮套餐 |
| Secondary | `#ff8fa3` | 糖果粉：标签、色块、步骤 |
| Text | `#2b2540` | 深紫墨 |
| Accent | `#2ec4b6` | 薄荷：对勾、荧光笔下划线、气泡 |
| Surface | `#fff9f2` | 奶油 |
| Border | `#e8dff5` | 淡紫描边 |

## 字体
标题 Quicksand 700（圆体）；正文 Nunito 600/700。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏左文右图：标题里一个短语带薄荷色荧光笔下划线，右侧是流动的粉色 blob + 倾斜图片 + 两个对话气泡（「Kitchen done in 3 weeks!」）。
2. 区块之间用 SVG 波浪分隔，背景在奶油 / 淡粉 / 淡薄荷之间交替。
3. 三个套餐卡：中间那张反色（紫底）并有「Most loved」标签，价格是「from RM xx」且公开。
4. 「Budget buddy」预算计算器用胶囊选项（房间 / 面积 / 档次），右侧紫色总结卡给出预算区间。
5. 步骤卡的数字是一个「气泡形」小方块（三圆角一尖角）。

## 不要
- 不要硬边框 + 硬阴影（那是 curve-modern）；不要深色与大写字体。
- 不要专业工程感的表格与蓝图线（那是 blueprint-build）。
- 不要照片叠字；图片放在圆角卡里。
- 不要出现价格以外的「询价」模糊用语。
