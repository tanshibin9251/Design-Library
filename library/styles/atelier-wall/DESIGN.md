# Atelier Wall

> 自有原创母版，授权 ok。

- **适合**：Landing / Company / Portfolio；在线美术、插画、设计课程学校、工作室教学站

## Feel
美术馆的白墙。作品是主角，页面几乎没有装饰；用一个钴蓝点缀，像墙上的展签。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#121212` | 黑：标题、线、按钮 |
| Secondary | `#7a7a75` | 灰：展签小字 |
| Text | `#1b1b1b` | 正文 |
| Accent | `#2547d0` | 钴蓝：标志方块、序号、悬停 |
| Surface | `#fbfaf7` | 画廊白 |
| Border | `#e3e1da` | 细线 |

## 字体
标题 Epilogue 800（字距 -.045em）；正文 Be Vietnam Pro。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶栏三栏对称：左菜单、中间 logo（黑字 + 一个钴蓝小方块）、右菜单与「Enrol」线框按钮；没有色块。
2. 作品墙：12 栏网格里大小不一的「画」，底端对齐像挂在同一高度；每幅下方是展签（作品名 / 作者、媒介、年份），可按类型过滤。
3. 课程（Studios）是大号数字行：01 02 03 04，标题与说明，配一幅横构图的作品占位。
4. Before / After：一根竖线滑杆，左 Week 1、右 Week 12，拖动即时对比。
5. 页脚是一个巨大的 wordmark。

## 不要
- 不要卡片阴影、圆角、渐变块；作品图片本身除外。
- 不要彩色背景分区；背景只用白与极浅灰。
- 不要超过一个强调色。
- 不要在图片上叠文字（展签放在图片下方）。
- 不要超过三个字号层级。
