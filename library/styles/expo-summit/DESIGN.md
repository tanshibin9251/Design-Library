# Nexus Summit（亚洲产品设计峰会）

> 自有原创母版，授权 ok。

- **适合**：Landing；会议、展会、峰会、活动

## Feel
高能量、渐变、倒计时。青紫渐变 + 近黑文字，大数字倒计时与可切换议程。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#6d28d9` | 紫：渐变起点、按钮 |
| Secondary | `#4b5563` | 石板灰 |
| Text | `#0b0b12` | 近黑 |
| Accent | `#06b6d4` | 青：渐变终点、标签 |
| Surface | `#ffffff` | 白 |
| Border | `#e5e7eb` | 浅灰线 |

## 字体
标题 Red Hat Display 900；正文 Red Hat Text。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏是两个径向渐变光斑 + 超大字重标题（关键词渐变填充）+ 4 格倒计时 + 日期地点胶囊。
2. 议程用「Day 1 / Day 2」胶囊切换（纯 CSS 单选），每场一行：时间 / 标题 / 类型标签。
3. 票务三档，中间 Pro 反色渐变卡；每档有「剩余票数」提示。
4. 讲者是大圆角方形肖像。

## 不要
- 不要深色玻璃拟态（那是 neon-nexus / aurora-cowork）。
- 不要硬边框黑线（那是 neobrutal）。
- 不要用超过两种渐变色。
