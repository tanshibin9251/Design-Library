# Oakline Furniture（橡木线家具）

> 自有原创母版，授权 ok。

- **适合**：Ecommerce；实木家具、定制家具、家居品牌
- **适合站型**：ecommerce

## Feel
温暖、踏实、有木头的重量。奶油底 + 橡木棕 + 陶土橙点缀。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#6b4a2f` | 橡木棕：陈列区块、标签、页脚 |
| Secondary | `#2f3b34` | 森林绿：顶部公告条、深色区 |
| Text | `#2b231c` | 正文 |
| Accent | `#b85c2e` | 陶土橙：热点针、序号、价格强调（每屏 ≤ 2 处） |
| Surface | `#f5efe4` | 奶油底 |
| Border | `#dccfb9` | 分隔线 |

## 字体
标题 Young Serif 400；正文 Figtree。中文配 Noto Serif SC / Noto Sans SC，不要斜体。

## 构图特征（Design signature）
1. 首屏左 5 / 右 7 的不对称分栏：左侧大标题 + 「按房间选购」胶囊，右侧整幅房间场景，场景上有 3 个可悬停 / 聚焦的商品热点（shop the room）。
2. 商品卡必须带三样信息：尺寸（W×D×H）、可选木色小圆点、交期标签（"3–4 wks" / "In stock"）。
3. 木色用圆形样板（swatch）而不是色块卡，并提供「免费样板」入口。
4. 分类页用左侧竖向筛选栏 + 3 列网格，不用顶部胶囊筛选。
5. 手工 / 保固信息用三列大序号（01 02 03）加框线表格，不用图标卡。

## 不要
- 不要整页白底 + 细线条的「北欧留白」感（那是 `nordic-interiors`）。
- 不要把交期、尺寸藏在详情页里。
- 不要堆满家具库存图；每个商品只放一张主图 + 细节图。
- 不要同一页出现超过两种强调色。
