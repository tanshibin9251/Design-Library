# Tsukimi Ryokan（月見荘）

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；温泉旅馆、民宿、山间小住宿，主打「夜晚」与「月」

## Feel
夜里的日式旅馆：墨黑底、月白字、一点朱红印章。灯光很低，内容像在拉门后面慢慢出现。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#efe6d0` | 月白：标题、月亮、描边、按钮线 |
| Secondary | `#a79d88` | 灰米：小标、说明 |
| Text | `#e2dac8` | 正文 |
| Accent | `#c8442f` | 朱红：「予約」印章按钮、汉字序号（极少用） |
| Surface | `#14120f` | 墨黑 |
| Border | `#322e27` | 细线 |

## 字体
标题 Yuji Syuku（书法感明朝，字距 .1em 以上）；正文 Noto Sans JP 300。中文可换 Noto Serif SC。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏是「今晚的月」：JS 按当天日期算月相并画成 SVG 大月亮，置于障子格栅（细线网格，向下渐隐）之后；标题横排在左下，月相名（十三夜 / 満月…）在右下。
2. 顶栏横排，菜单项带汉字序号（一二三四），右侧方形朱红「予約」印章；没有竖排导航。
3. 客房是横向「襖」手风琴：四块并排，悬停 / 点击的那块展开露出介绍与价格，其余只剩汉字序号与名称；手机上改成竖直堆叠且内容常显。
4. 会席（晚餐）和温泉礼仪是细线竖向时间轴，左侧大汉字菜名，圆点串在线上。
5. 四季是四列描边空心大汉字（春夏秋冬），悬停填一层淡月白。
6. 预约页的估价随客房 / 晚数 / 人数即时更新。

## 不要
- 不要金色（gilded-ledger 已用）；强调色只能是朱红，且整页不超过一两处。
- 不要竖排大标题或左侧固定竖栏（reflex-point 已用）。
- 不要加图标、Emoji、渐变色块、阴影、圆角。
- 不要库存图堆叠樱花、富士山、艺伎。
- 不要超过三个字号层级。
