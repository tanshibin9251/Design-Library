# Ippon Dojo（一本道場）

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；空手道、柔道、合气道等武道馆，有年龄段与级位的课程制场馆

## Feel
黑白、毛笔、警示黄。像道场墙上的一张黑纸大字，直接、有力，不装饰。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#111111` | 墨黑：顶栏、标题、粗线、页脚 |
| Secondary | `#6b6b6b` | 灰：次要说明 |
| Text | `#1a1a1a` | 正文 |
| Accent | `#f2c200` | 警示黄：按钮、选中、胶带条、顶栏下边 |
| Surface | `#f4f2ec` | 道服白 |
| Border | `#111111` | 3px 粗描边 |

## 字体
标题 Yuji Boku（毛笔楷体）；正文 BIZ UDPGothic（UD 无衬线，笔画清晰）。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏是黑底「一本。」超大毛笔字，后面一个黄色「円相」圆在加载时被一笔画出（stroke-dashoffset），底边斜切，斜贴一条黄色滚动胶带。
2. 顶栏黑色，logo「一本」下带黄线；菜单大写字距，悬停整格变黄；底边 6px 黄线。
3. 级位阶梯：七条横向色带，宽度随级位递增，点选后右侧黑色面板显示大号汉字、说明、考核清单。
4. 时间表是 7 列 × 周，课程块分成人 / 儿童 / 通用三种底色，上方筛选按钮即时过滤。
5. 所有卡片用 3px 黑线 + 硬投影（无模糊），悬停时「按下去」。

## 不要
- 不要朱红、不要金色、不要墨绿。强调色只能是黄。
- 不要竖排首屏标题（reflex-point）；不要灯笼、樱花、富士山。
- 不要圆角、渐变、柔和阴影。
- 不要加图标、Emoji。
- 不要超过三个字号层级。
