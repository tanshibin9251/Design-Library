# Gilded Ledger（金边金融）v2

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；家族办公室、独立财富管理、私人银行、财务顾问的官网

## Feel
一本账簿：横格纸、铜色页边线、等宽数字。克制、清楚、把费用和限制写在明面上，不靠黑金装饰。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#26282b` | 石墨：标题、粗线、按钮、页脚 |
| Secondary | `#8d8a82` | 暖灰：次要块、虚线 |
| Text | `#26282b` | 正文 |
| Accent | `#b4683a` | 铜：页边线、罗马序号、选中 |
| Surface | `#f4f1ea` | 账簿纸 |
| Border | `#d9d4c7` | 细线 |

## 字体
标题 Cardo 700（学院派古典衬线，数字清晰）；正文 Albert Sans。数字一律使用等宽数字（tabular-nums）。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 页面背景是 36px 的横格账簿纸，首屏左侧有一条细铜色「页边线」。
2. 首屏右侧是「At a glance」账页：成立年份、服务家庭数、每位经理客户数、平均关系年限、销售产品数「None」，点线分隔、右对齐数字。
3. 章节用罗马数字 I / II / III 作小标，下加粗线，像账簿分栏。
4. 「资产配置示意」：五档风险按钮，分栏条按档位变化（股票 / 债券 / 现金 / 另类），下方给出典型波动区间说明，全部标注「仅为示意」。
5. 「费用，写明白」直接给分段费率表，右列数字对齐。页脚固定带风险与免责声明。

## 不要
- 不要黑底金字、金色渐变、金边装饰（旧版 / tsukimi-ryokan / diamond-shop）。
- 不要上升箭头、硬币、股票走势图和库存图。
- 不要夸大收益的文案；所有数字注明「示意」。
- 不要超过三个字号层级。
