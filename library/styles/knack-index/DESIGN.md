# Knack Index

> 自有原创母版，授权 ok。

- **适合**：Blog；生活小知识、清洁 / 理财 / 健康 / 数码速查站、「怎么办」类内容库

## Feel
一堆彩色索引卡片。大搜索框、四种分类色、每条答案三行内说完。轻、直接、有用。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#2b2d42` | 墨蓝：标题、粗描边、页脚 |
| Secondary | `#8d99ae` | 灰蓝：小标、点线 |
| Text | `#2b2d42` | 正文 |
| Accent | `#ff7f6e` | 鲑鱼红：标记、序号、悬停 |
| Surface | `#f5f3ee` | 暖灰白 |
| Border | `#ddd8cc` | 虚线 |

分类色（Home 鲑鱼红 / Money 蛋黄 / Health 薄荷 / Tech 天蓝）是内容数据色，只用在卡片顶条、分类圆点上。

## 字体
标题 Gabarito 700（几何无衬线，字距 -.03em）；正文 Hanken Grotesk。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏是一个超大搜索框（3px 墨蓝线 + 6px 硬投影），下面一排分类色胶囊；输入即时过滤下方所有答案卡。
2. 答案是「索引卡」：顶部一条分类色带，标题可点开（`<details>`），答案三行内；不跳页。
3. 「每日小贴士」是整块深色横幅，左边巨大的编号，按日期轮换。
4. A–Z 页是字母索引条加按字母分组的列表，右侧带分类标签。
5. 指南页：编号方块步骤 + 右侧「你需要」「别这样做」两个盒子；清单页有进度条，勾选存在浏览器里。

## 不要
- 不要手绘贴纸、胶带、方格纸；不要渐变和毛玻璃。
- 不要长文章式排版；答案应该一屏看完。
- 不要加图标、Emoji。
- 不要超过三个字号层级。
