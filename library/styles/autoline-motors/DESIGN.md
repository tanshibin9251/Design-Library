# Autoline Motors（飞驰汽车）v2

> 自有原创母版，授权 ok。

- **适合**：Company / Ecommerce；认证二手车行、新车服务中心、汽车经销商

## Feel
规格表和试驾单：钛灰、纯白、一道速度蓝。信息密度高，给出对比而不是形容词。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#101820` | 机油黑：标题、对比表头、金融面板、页脚 |
| Secondary | `#8d99a6` | 钢灰：说明文字、表格首列 |
| Text | `#101820` | 正文 |
| Accent | `#0aa5ff` | 速度蓝：选中框、最佳值、斜切按钮 |
| Surface | `#eef1f4` | 浅钛灰 |
| Border | `#d2d8df` | 细线 |

## 字体
标题 Chakra Petch 700（棱角感科技体，大写）；正文 Inter。中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏下方是三辆车的卡片，每张有「Compare」勾选框；勾两辆以上，下方立刻出现并排规格表，每项最优值用蓝色加粗。
2. 车图占位上是一个用 clip-path 画的车身剪影，卡片选中时蓝框。
3. 按钮是左右斜切的平行四边形。
4. 整块深色「月供」计算器：价格、首付、年限三个滑块。

## 不要
- 不要深色斜切全屏首图、红色（旧版）。
- 不要夸大「最低价」「全城最平」。
- 不要车标、方向盘、车钥匙图标。
- 不要超过三个字号层级。
