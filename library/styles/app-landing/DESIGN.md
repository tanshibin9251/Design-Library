# Pocket App（应用落地页）

> 自有原创母版，授权 ok。

- **适合**：Landing；App 下载页、SaaS 产品页、课程售卖页

## Feel
轻盈、有点未来、手机是主角。紫 → 蓝绿渐变 + 近黑，居中大标题与悬浮卡片。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#6d4aff` | 紫：渐变起点、按钮 |
| Secondary | `#6b7280` | 灰 |
| Text | `#11121a` | 近黑 |
| Accent | `#14c8a8` | 青绿：渐变终点、对勾 |
| Surface | `#fbfbff` | 微紫白 |
| Border | `#e6e6f2` | 浅线 |

## 字体
标题与正文都用 Onest（标题 800，字距 -.04em）。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏居中：小胶囊徽章 + 渐变关键词的大标题 + 两个按钮；下方是一台 CSS 画的手机（圆角黑边框 + 屏幕内账单卡），两侧悬浮的小卡片缓慢上下浮动。
2. 功能三栏是淡紫底大圆角卡，顶部渐变方块图标。
3. 定价用「月付 / 年付」纯 CSS 切换，推荐档用渐变边框。
4. 更新日志是竖线时间轴。

## 不要
- 不要深色玻璃拟态（neon-nexus / aurora-cowork）。
- 不要多个手机拼贴的套路。
- 不要超过两种渐变色。
