# Fermata Piano

> 自有原创母版，授权 ok。

- **适合**：Landing / Company；在线钢琴、吉他、声乐等乐器课程平台、琴行网课站

## Feel
乐谱纸：米色纸、墨黑线、一点青绿。安静、准确，像翻开一份曲谱。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#201c17` | 墨：标题、五线谱线、琴键、按钮 |
| Secondary | `#8a7d68` | 旧纸灰褐：说明、边线 |
| Text | `#2a251f` | 正文 |
| Accent | `#0f7b7b` | 青绿：音符悬停、序号、重点斜体 |
| Surface | `#f5efe0` | 曲谱纸 |
| Border | `#d8cdb4` | 细线 |

## 字体
标题 Old Standard TT（古典衬线）；正文 Libre Franklin。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶栏是一张「五线谱」：5 条横线贯穿，logo 是高音谱号，导航链接是落在线上的「音符」（椭圆符头 + 文字），悬停变青绿。
2. 首屏右侧是真能弹的钢琴键盘（CSS + WebAudio），点键出音名和唱名，可点「音阶 / 琶音 / 小星星」自动演奏。
3. 课程是「音乐会节目单」：罗马数字 I II III IV、标题、说明、时长、价格，细线分隔；悬停整行缩进。
4. 课程页里有节拍器：BPM 滑块、四拍圆点（第一拍黑色）、WebAudio 点击声。
5. 页脚右上角有一个小斜体「fine.」（乐曲结束记号）。

## 不要
- 不要黑白琴键的大幅装饰图或钢琴剪影库存图。
- 不要金色 / 暗金（gilded-ledger）；强调色只能是青绿。
- 不要圆角、渐变、阴影（琴键投影除外）。
- 不要超过三个字号层级。
