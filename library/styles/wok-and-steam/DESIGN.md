# Wok & Steam（家常菜）

> 自有原创母版，授权 ok。

- **适合**：Blog / Company；中餐家常菜食谱站、华人饮食博客、菜谱库

## Feel
家里的饭桌：瓷盘、热气、红印章、豆瓣酱的红。亲切，解释清楚，不装。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#2b1d16` | 酱油黑棕：标题、描边、页脚 |
| Secondary | `#4f7f6f` | 青瓷绿：次要说明、点线 |
| Text | `#2b1d16` | 正文 |
| Accent | `#c8372d` | 辣椒红：印章、按钮、强调 |
| Surface | `#f9f3e6` | 米纸色 |
| Border | `#e2d4b8` | 细线 |

## 字体
标题 ZCOOL XiaoWei（中文优先的衬线体）；正文 Noto Sans SC。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. logo 是旋转 -4° 的红色方章「家」；导航每项下带一行中文小字（菜谱 / 今天 / 技法 / 调料）。
2. 首屏右侧是一只 CSS 画的「盘子」：同心圆瓷边、盘中色点，上方三缕蒸汽循环上升。
3. 菜品缩略图全是圆形（盘子），带 3px 描边，悬停轻微旋转；不用方形图。
4. 食谱页：左侧粘性「食材」卡（份量 ± 按钮自动换算分数、可勾选划掉），右侧步骤用中文数字圆章（一二三四），每步可标火力格。
5. 「今天吃什么？」：点按钮，菜名在 1 秒内快速滚动后停下。

## 不要
- 不要竖排大标题、侧栏（日式模板已用）；不要渐变。
- 不要用金色 / 墨绿 / 深紫。
- 不要俗套的龙、灯笼、红金背景。
- 不要加图标、Emoji。
- 不要超过三个字号层级。
