# Civic Hall（市政厅）v2

> 自有原创母版，授权 ok。

- **适合**：Company / Blog；市政厅、地方议会、社区委员会、公共服务机构的信息与办事入口站

## Feel
政府服务目录：白底、粗黑线、紫色标题、一抹警示黄。重点是「能办成事」和「无障碍」，不是形象。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#3f2a73` | 议会紫：标题链接、按钮、顶栏底边、页脚 |
| Secondary | `#5b5675` | 灰紫：日期、说明 |
| Text | `#1b1b1b` | 正文与粗线 |
| Accent | `#ffdd00` | 警示黄：悬停、标签、焦点环 |
| Surface | `#ffffff` | 白 |
| Border | `#b9b4c9` | 细线 |

## 字体
标题与正文都用 Atkinson Hyperlegible（为低视力读者设计，易混字形差异大）。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 最顶是黑色无障碍工具条：A− / A / A+ 文字缩放、高对比度开关（页面实时切换）、语言切换。
2. 首屏不是形象图，而是一句问题「What do you need to do?」，一个大搜索框和 6 个任务格（Pay / Report / Apply / Book / Find / Contact），输入文字即时过滤。
3. 任务格用 3px 黑线拼成「表格」，悬停整格变黄，不用图标、不用图片。
4. 右栏是「下次会议」（日期方块）和「垃圾收集日查询」（输入邮编，示范性计算下一次日期）。
5. 所有链接带下划线；焦点环 4px 黄色；页脚含 24 小时紧急电话框。

## 不要
- 不要金色、墨绿、全大写 Art Deco 标题（旧版）。
- 不要装饰图、渐变、毛玻璃、悬浮卡片阴影。
- 不要靠颜色单独传达信息；所有状态要有文字。
- 不要小于 16px 的正文。
