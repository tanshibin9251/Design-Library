# Washoku Note（和食ノート）

> 自有原创母版，授权 ok。

- **适合**：Blog；日式家庭料理食谱站、和食教学博客、料理笔记

## Feel
一本方格笔记本。奶油纸、抹茶绿、柿子色小点缀，贴纸胶带和手写标题；像在笔记本边上写的食谱。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#3f5a3a` | 抹茶绿：标题、描边、按钮 |
| Secondary | `#a3b18a` | 鼠尾草：胶带、方格线、荧光笔 |
| Text | `#2e2a25` | 正文 |
| Accent | `#e0763a` | 柿子橙：序号、划线、悬停 |
| Surface | `#fbf8ef` | 笔记本纸 |
| Border | `#d9d3c0` | 虚线 |

## 字体
标题 Klee One（教科书式手写体）；正文 Zen Maru Gothic。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 整个页面背景是 28px 方格纸（方眼ノート）；内容放在「便签」上，顶部贴一条半透明胶带，略微旋转。
2. 导航不在顶部，是固定在右侧的「索引标签」：竖排（レシピ / 味噌汁 / 旬 / 基本），悬停时从边缘滑出，手机上折叠为菜单。
3. 食谱卡不用圆角和阴影，只有 2px 墨绿线 + 斜纹占位，交替轻微旋转（像随手贴的）。
4. 味噌汁ビルダー：选 出汁 / 味噌 / 配料（可多选），右侧「碗」卡实时给出顺序和时间。
5. 旬の食材：12 个月份按钮，默认当月，显示该月时令食材与做法。

## 不要
- 不要竖排大标题、侧边固定竖栏（reflex-point 已用）；索引标签只能在右侧。
- 不要深色模式、不要渐变。
- 不要樱花、鸟居、艺伎等和风套路图案。
- 不要加图标、Emoji。
- 不要超过三个字号层级。
