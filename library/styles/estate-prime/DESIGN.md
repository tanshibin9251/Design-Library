# Prime Estates（顶级地产）v2

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；房产中介、地产代理、租售平台

## Feel
把「找房」放在第一屏：搜索条、列表、月供计算器同屏；颜色是钢蓝加陶土橙，纸一般的米色。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#243b53` | 钢蓝：标题、搜索框边、月供面板、页脚 |
| Secondary | `#81b29a` | 鼠尾草绿：标签、渐变 |
| Text | `#243b53` | 正文 |
| Accent | `#e07a5f` | 陶土橙：按钮、屋顶 logo |
| Surface | `#f4f1de` | 米色 |
| Border | `#dcd6bd` | 细线 |

## 字体
标题 Libre Caslon Text 700；正文 Mulish。中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏是一条白色搜索条：买 / 租开关、区域、卧室数、最高价和「Search」，结果即时过滤并显示数量。
2. 房源是横排卡片：左侧图块 + 右侧价格、地段、床 / 卫 / 面积标签。
3. 右侧粘性「月供面板」：滑块（房价、首付、年限、利率）实时算每月还款。
4. logo 是小房子轮廓（clip-path），顶栏右侧「Book a viewing」。

## 不要
- 不要全屏豪宅大图加居中大标题（旧版）。
- 不要金色、深蓝黑豪华风（gilded-ledger / heirloom-classic）。
- 不要夸大升值的文案。
- 不要超过三个字号层级。
