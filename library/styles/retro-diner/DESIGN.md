# Sunny's Diner（阳光餐车）v2

> 自有原创母版，授权 ok。

- **适合**：Company / Landing / Ecommerce；美式复古餐厅、汉堡店、奶昔店、深夜食堂

## Feel
五十年代的美式餐车：樱桃红、青绿、黑白方格地砖，柜台上有一张刚打印的小票。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#c8102e` | 樱桃红：顶栏、标题、按钮 |
| Secondary | `#00a3a1` | 青绿：副按钮、投影、悬停 |
| Text | `#14213d` | 深海军蓝：正文、粗线、页脚 |
| Accent | `#14213d` | 同上，用于强调线 |
| Surface | `#fff4e0` | 奶油色 |
| Border | `#14213d` | 3px 粗线 |

## 字体
标题 Bungee（霓虹招牌式粗体，全大写）；正文 Manrope。中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶栏上方一条黑白方格地砖带（conic-gradient），顶栏红色带 6px 黑下沿。
2. 首屏右侧是「点餐小票」：点左边的菜品，右边打印出带锯齿下沿的等宽字体小票，可删除项，含 6% 税的合计。
3. 按钮、卡片都是 3px 黑边 + 黑色 / 青绿色硬投影。
4. 「Shake of the month」三张卡用青绿硬投影。

## 不要
- 不要昭和喫茶店的遮阳篷、点线菜单（kissa-showa）。
- 不要霓虹发光、唱片图标、Emoji。
- 不要超过三个字号层级。
