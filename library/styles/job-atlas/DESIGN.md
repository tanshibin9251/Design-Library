# Job Atlas（职业图鉴）

> 自有原创母版，授权 ok。内容结构（模块 → 领域 → 职位档案）来自 `Aiden Personal/career` 的职业科普笔记；视觉从深色渐变站重做成「图鉴」。`career/private/` 的个人资料没有使用。

- **适合**：Blog / Company；职业科普、升学与就业指导、人才平台的职位百科、学校 / 社区的职业探索站

## Feel
一本放在书桌上的野外图鉴。暖纸色、墨青色、每一页像一张贴了编号的标本图版，职业被「分类」而不是「推销」。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#1b3a4b` | 墨青：标题、当前页签、阶梯描边；也是第 I 书架（通用职能）的颜色 |
| Secondary | `#5b57a6` | 靛紫：第 IV 书架（科技专业）、正面清单 |
| Text | `#22303a` | 正文 |
| Accent | `#c98a1b` | 赭黄：高亮下划线、第 III 书架（销售顾问）、进度线 |
| Surface | `#f4eee2` | 暖纸 + 22px 淡点阵底纹 |
| Border | `#d9cfbd` | 细线、虚线 |
另有一个本地变量 `--m2: #b24a6b`（玫瑰红）给第 II 书架（营销创意）。四个书架颜色只用来「分类编码」，不做渐变。

## 字体
标题 **Zilla Slab** 600（带图鉴感的粗衬线 / 板衬线）；正文 **Lato**。中文配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。无斜体、无彩虹渐变文字。

## 构图特征（Design signature）
1. **页眉像书的「书眉 + 书签页签」**：第一行只有 logo 与一个搜索入口，第二行是文件夹式页签（Atlas / All fields / 四个书架 / Match / Compare / Switch），当前页是实心墨青，下面压一条 2px 墨线。
2. **「抽屉」首屏**：右边是深色抽屉里 24 个领域徽章的 6×4 方格（编号 01–24），左边是一个带硬投影的大搜索框，打字即出职位下拉。
3. **标本图版 Plate**：每个领域是一张双线描边的卡，顶部「PLATE 07 · III」编号，中间圆形徽章（外面再一圈虚线），悬停时徽章转 14°。
4. **职位档案**三栏：左侧目录（随滚动高亮）+ 阅读列 + 右侧「At a glance」标本数据卡。阅读列固定九节：一天 / 工作内容 / 工具 / 薪资 / 入行 / 发展 / 价值 / 优缺点 / 误解。
5. **日晷（Sundial）**：把「真实工作情景」画成 8am–6pm 的半圆日晷，时间点是编号圆点，与右侧时间列表联动悬停。
6. **薪资阶梯**：三级（Junior / Experienced / Senior）画成悬浮的区间柱 + 点线阶梯，横轴是年资，纵轴是整数刻度（RM k）。
7. **地铁线发展路径**：主线是模块色，转行分支是点线终点站。**转行地图**是放射形：中心当前职位，周围邻近职位。
8. 工具页：Compare（两把阶梯并排 + 一句话判断）、Match（点选兴趣即时排序）、Switch（可迁移技能清单）。
9. 24 个领域徽章、10 个兴趣图标、所有 UI 图标都是 24 格自绘 SVG（1.5–1.7 描边、圆头），没有 Emoji。

## 不要
- 不要 Emoji、不要彩虹渐变文字、不要模糊光斑、不要深色玻璃卡片（旧版 career 的样子）。
- 不要把薪资写成一个数字：永远是区间，并标明「示意数据，请换成自己核对过的数据」。
- 不要超过三种字体：Zilla Slab / Lato（Noto SC 作中文回落）。
- 不要只靠颜色区分书架：每个书架同时有罗马数字 I–IV。
- 不要把个人简历、求职记录、证书放进来（`career/private/`）。
