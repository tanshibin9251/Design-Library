# Thai Touch（泰式触感）

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；泰式按摩、SPA、足底按摩、礼品券

## Feel
温暖、手工、有仪式感。柚木深褐 + 藏红金 + 米色，手绘波浪线与莲花装饰，拱门形图片。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#5a3418` | 柚木深褐：标题、深色引言块 |
| Secondary | `#7b5a2e` | 暗金棕：页脚、小标签 |
| Text | `#3a2614` | 深褐正文 |
| Accent | `#b8860b` | 藏红金：按钮、价格、手绘线 |
| Surface | `#fbf3e1` | 象牙米色 |
| Border | `#e6d6b3` | 浅金线 |

## 字体
标题 Gloock 400（有温度的粗衬线）；正文 Karla。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 顶部居中对称：品牌字标 + 手绘莲花分隔线 + 一行居中菜单，不是左右分栏。
2. 主视觉图片被裁成「拱门」（顶部半圆 230px）并带一圈虚线外框，底部有手绘莲花。
3. 标题里一个词带手绘波浪下划线；按钮有双层（实线 + 虚线外圈）。
4. 疗程以「菜单」形式呈现：名称 ………… 价格，中间是点线，下面一行小字说明（不是卡片）。
5. 套餐卡也使用拱门形；整页没有直角照片。

## 不要
- 不要冷色、极简留白（calm-spa / reflex-point）。
- 不要石头、竹子、莲花库存图堆叠；手绘线条才是装饰。
- 不要把价格藏起来；菜单必须显示。
- 不要超过一种强调色（金）。
