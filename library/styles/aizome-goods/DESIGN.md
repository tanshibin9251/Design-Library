# Aizome Goods（藍染）

> 自有原创母版，授权 ok。

- **适合**：Ecommerce / Company；天然藍染的亚麻、棉布、纸品与家居小物，小批量手工店

## Feel
日式手作、安静的蓝。米白棉布底 + 靛蓝大色块 + 一点金茶色印章；像一面挂着的暖帘（noren）。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#1f3a5f` | 靛蓝：标题、按钮、暖帘色块、页脚 |
| Secondary | `#6f7f93` | 灰蓝：小标、日文副标 |
| Text | `#1d2733` | 墨蓝黑 |
| Accent | `#b98322` | 金茶：印章、编号、选中态（极少用） |
| Surface | `#f4efe4` | 未漂白棉布 |
| Border | `#d9d1bf` | 细线 |

## 字体
标题 Zen Old Mincho 500（字距 .06em+）；正文 Zen Maru Gothic。中文可换 Noto Serif SC。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏是「暖帘」：横杆下挂五条高低不一的靛蓝布片，每条竖排分类名，悬停时像布一样微微摆动；标题在帘下方，不叠在图上。
2. 顶栏三栏对称：左右菜单中间是方形印章 + 字标；菜单项下带一行日文小字；「More」展开全部页面。
3. 色见本：六格靛蓝深浅（按浸染次数排序，瓶覗 → 褐），点选后下方显示日文名、说明、浸染次数大数字；这是整站的主互动。
4. 商品卡是 3:4 色块图 + N° 编号 + 英日双名 + 三个色点，无阴影、无圆角。
5. 页脚顶部是青海波（seigaiha）细线带，下方整块靛蓝。

## 不要
- 不要加图标、Emoji、渐变、阴影、圆角。
- 不要用竖排大标题做首屏（reflex-point 已用）；竖排只用在暖帘的分类名。
- 不要用朱红色；强调色只能是金茶。
- 不要库存图堆叠竹子、樱花、鸟居。
- 不要超过三个字号层级。
