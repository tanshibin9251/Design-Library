# Sugar & Crumb

> 自有原创母版，授权 ok。

- **适合**：Blog；烘焙与甜点食谱站、蛋糕博客、烘焙教学笔记

## Feel
糖霜和纸杯蛋糕：奶油粉底、莓果紫的粗描边、糖珠点点。圆滚滚、甜，但步骤和克数很严肃。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#8a3b55` | 莓果：标题、描边、按钮、页脚 |
| Secondary | `#f7c6c7` | 腮红粉：标签、表头、色块 |
| Text | `#4a2c35` | 正文 |
| Accent | `#f2b84b` | 黄油黄：强调、序号、结果卡 |
| Surface | `#fff8f2` | 奶油白 |
| Border | `#f1d6cf` | 点线 |

## 字体
标题 Grandstander 800（圆润卡通体）；正文 Mulish 600。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 页面背景是糖珠点阵（粉色圆点 34px 间距）。
2. logo 居中，下方导航是「纸杯标签」：胶囊上沿、直角下沿、不同粉彩色，悬停上跳；底边 5px 描边像杯底。
3. 首屏右侧是 CSS 画的三层蛋糕（奶油糖霜扇贝边、樱桃、盘子），旁边贴一张旋转的「Fresh today」小贴纸。
4. 食谱卡片是 28px 大圆角 + 3px 描边；悬停轻微旋转。
5. 烤盘换算器：选「食谱用的」和「我有的」形状与尺寸，算面积比，给出材料倍数和烘烤时间提示。

## 不要
- 不要手绘风、方格纸（washoku-note）；不要深色模式。
- 不要渐变和模糊阴影；边框一律纯色粗线。
- 不要用蛋糕、勺子的 Emoji。
- 不要超过三个字号层级。
