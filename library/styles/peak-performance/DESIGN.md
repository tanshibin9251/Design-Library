# Peak Performance（巅峰科技）

> 自有原创母版，授权 ok。

- **适合**：Ecommerce；高端穿戴、竞速跑鞋、科技型运动品牌

## Feel
冷、精确、有仪器感。近黑底 + 钛灰 + 信号红，全部围绕数据与圆环。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#10141c` | 深蓝黑：卡片底、渐变 |
| Secondary | `#8d9bb3` | 钛灰：副标题与次要数据 |
| Text | `#eef2f8` | 冷白 |
| Accent | `#ff3b5c` | 信号红：CTA、圆环、数据强调（每屏 ≤ 2 处） |
| Surface | `#07090d` | 近黑底 |
| Border | `#232a38` | 1px 发丝线 |

## 字体
标题 Unbounded 700（宽体科技感，字距 -.04em）；正文 Sora。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 导航是悬浮的毛玻璃圆角条（fixed、backdrop-blur），不是通栏。
2. 首屏居中：渐变渐隐的大标题 + 慢速旋转的锥形光斑 + 圆形设备图，由 3 圈 conic-gradient 活动环组成（84 / 62 / 41）。
3. 紧接一排 KPI 数字带（14 d / ±1 m / 38 g / 10 ATM），只用发丝线分隔。
4. bento 卡片使用 24px 大圆角、深色渐变，内部放迷你柱状图与数字。
5. 商品详情页是「规格 Tabs + 两列规格表」，实验室页每个声明都带数据。

## 不要
- 不要暖色和纸张质感（那是 trailhead）；不要厚边框和硬阴影（那是 sprint-gear）。
- 不要 stock 运动员照片叠大字；用数据与圆环做主视觉。
- 不要超过一种强调色（红）；蓝色只作冷光背景。
- 不要图标库图标，用数字和线条。
