# Clay Beauty（陶土美妆）v2

> 自有原创母版，授权 ok。

- **适合**：Company / Ecommerce；皮肤护理型彩妆、美妆独立品牌、美容工作室

## Feel
陶土、桃肤色、可可棕。柔和、慢、靠近皮肤；一切形状都有拱形（像陶罐开口）。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#5c3b3b` | 可可棕：标题、按钮、公告条、页脚 |
| Secondary | `#f0cdbf` | 浅桃：色号拱门背景 |
| Text | `#3b2626` | 正文 |
| Accent | `#c4745a` | 陶土：强调、悬停 |
| Surface | `#fdf6f1` | 暖白 |
| Border | `#ecd5c8` | 细线 |

## 字体
标题 Prata；正文 Jost 300。中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏右侧是「色号查找」：拱形外框（顶部半圆）里一个圆形色块，选冷 / 中 / 暖底调，拖肤色深度（Fair→Deep），色块实时变色并给出色号名和编号。
2. 商品图是拱门形状（顶部大圆角），不是方形图。
3. 顶部一条可可棕公告条（Free shade matching）；导航全大写字距。
4. 三栏价值观用细线隔开，不用卡片。

## 不要
- 不要紫色 + 红色的旧配色（旧版）；不要毛玻璃。
- 不要人脸库存图的大幅全屏背景。
- 不要夸大功效。
- 不要超过三个字号层级。
