# Maison Verde（绿荫美发沙龙）

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；美发、美容、造型

## Feel
时尚、大胆、拱形图片拼贴。祖母绿 + 腮红粉底，超大描边标题。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#14803c` | 祖母绿：标题、按钮、页脚 |
| Secondary | `#6b4c4c` | 暖灰褐：次要文字 |
| Text | `#1d1a1a` | 近黑 |
| Accent | `#ff8fa3` | 腮红粉：圆章、高亮 |
| Surface | `#f7efe9` | 暖白 |
| Border | `#e3d6cc` | 细线 |

## 字体
标题 Syne 700 全大写（宽体、带个性）；正文 Albert Sans。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 导航浮在首屏之上、无底色；首屏标题一行实心一行描边。
2. 右侧是三张拱形 / 半拱形图片重叠拼贴，中间一个旋转的腮红圆章「Free consult」。
3. 服务是「可展开价目表」（summary 行：名称 / 时长 / 起价），不是卡片。
4. 发型师卡片使用拱门头像和「Next: Today 3pm」胶囊；预约用 5 列时间格。
5. 前后对比滑块。

## 不要
- 不要白底细线极简（那是 clay-beauty / boutique-rose）。
- 不要柔和粉彩渐变。
- 不要圆角小卡片堆叠。
