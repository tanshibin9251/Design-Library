# Reflex Point（足点）

> 自有原创母版，授权 ok。

- **适合**：Company；足底按摩、整骨按摩，预约制小店

## Feel
日式留白、竖排文字、克制。象牙白底 + 墨绿 + 朱红一点，所有内容像一页书。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#2f3d33` | 墨绿：标题、按钮、深色边 |
| Secondary | `#7d8a7e` | 苔灰：英文小标 |
| Text | `#26302a` | 深墨 |
| Accent | `#d94f30` | 朱红：太阳圆点、序号、选中足区（极少用） |
| Surface | `#f7f5ef` | 和纸白 |
| Border | `#d8d6cb` | 极细线 |

## 字体
标题 Shippori Mincho 500（日式明朝，字距 .06em+）；正文 Zen Kaku Gothic New。中文可换 Noto Serif SC。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 导航是固定在左侧的 84px 竖栏：竖排 logo、竖排菜单、竖排「予約」按钮；内容整体右移。
2. 首屏标题是竖排（writing-mode:vertical-rl）「足から、ととのう。」，右半是大图加一个朱红圆点（太阳）。
3. 疗程列表是三列无色块的格子，仅用 1px 线分隔，英文名 + 日文副标 + 时长 + 价格。
4. 足裏マップ：SVG 足底分区，点选后右侧以细线表格显示对应区域；回数券用三个大数字（5 / 10 / 20）。
5. 整页只有一个朱红点；没有阴影、没有渐变、没有圆角。

## 不要
- 不要暖金手绘风（thai-touch）；不要粉彩 spa 风（calm-spa）。
- 不要库存图堆叠莲花、石头、竹子。
- 不要加图标、Emoji。
- 不要超过三个字号层级。
