# Nordic Interiors（北欧室内）v2

> 自有原创母版，授权 ok。

- **适合**：Portfolio / Company；室内设计工作室、软装与空间顾问、家居改造

## Feel
北欧的克制：燕麦色、橡木、鼠尾草灰和石灰墙。少说话，把材料和光放在前面。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#4a4f5c` | 板岩灰紫：标题、按钮、沙发块、页脚 |
| Secondary | `#9aa597` | 鼠尾草灰：小标、场景墙色 |
| Text | `#2e3138` | 正文 |
| Accent | `#b98f6c` | 橡木：下划线、日光、悬停 |
| Surface | `#f5f2ee` | 燕麦白 |
| Border | `#dcd6cc` | 细线 |

材料色板里的橡木 / 胡桃 / 石灰 / 亚麻等是内容数据色，仅用于材料色块。

## 字体
标题 Marcellus 400（古典罗马体，大写字距）；正文 Outfit 300。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏标题很大但只占左上，三张「房间」竖幅的高度不同（380 / 480 / 310px）并底边对齐；每张下面是三个圆形材料色点 + 项目名 + 材料清单。
2. 「材料库」是 12 个方形色块（橡木、亚麻、石灰华…），分类按钮过滤；悬停 / 点选时名称从底边滑出，下方文字说明怎么用。
3. 「光线研究」：一个用 CSS 画的房间（窗、光束、沙发、落地灯），滑块从黎明拖到黄昏，墙色、窗光、光束与灯晕实时变化。
4. 顶栏左边是大写字距的小 logo，链接只有下划线悬停，主 CTA 是细线框按钮。
5. 页脚是石板灰块，字号偏小、字重轻。

## 不要
- 不要黑白极简的作品大图墙（folio / atelier-wall）；不要大面积留白无信息。
- 不要木纹贴图、绿植插画、毛玻璃。
- 不要超过三个字号层级。
- 不要把「北欧」做成冷蓝；暖橡木始终是点睛色。
