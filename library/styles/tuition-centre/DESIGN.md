# BrightPath Tuition（明途补习中心）

> 自有原创母版，授权 ok。

- **适合**：Company / Landing；补习中心、培训班

## Feel
像笔记本方格纸的明亮学习站。深蓝 + 铅笔黄，厚描边硬阴影卡片，数据说话。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#1e3a8a` | 深蓝：顶栏、首屏、数据数字 |
| Secondary | `#475569` | 石板灰：次要文字 |
| Text | `#111827` | 深墨 |
| Accent | `#fde047` | 铅笔黄：高亮、按钮 |
| Surface | `#fffdf5` | 纸白 |
| Border | `#e5e1c8` | 方格线 |

## 字体
标题 Baloo 2 800（圆润）；正文 Lexend。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏深蓝带方格纸背景，右侧白色「成绩变化」卡：横向进度条 + 平均提升分数，硬阴影黄色偏移。
2. 首屏下一排四个大数字（人数 / 通过率 / A 数 / 年数）。
3. 年级入口是粗黑描边 + 5px 硬阴影的卡片，科目是小标签。
4. 课表是真正的周课表（粗圆角格子，手机上可横向滚动），不是图标列表。

## 不要
- 不要儿童卡通插画。
- 不要渐变与柔和阴影。
- 不要白色细线条企业风（那是 enterprise-blue / bright-academy）。
