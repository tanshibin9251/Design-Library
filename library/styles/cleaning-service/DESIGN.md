# Sparkle Nest（清洁到家）

> 自有原创母版，授权 ok。

- **适合**：Landing / Company；清洁、搬家、家居服务

## Feel
清爽、可信、报价是主角。深海蓝 + 薄荷，圆润按钮，首屏就能算价。

## 调色
| 角色 | HEX | 用在哪 |
|---|---|---|
| Primary | `#0c4a6e` | 深海蓝：标题、按钮、报价卡 |
| Secondary | `#475569` | 石板灰 |
| Text | `#0f172a` | 墨蓝黑 |
| Accent | `#5eead4` | 薄荷：选中、对勾、高亮 |
| Surface | `#fbfdfd` | 微蓝白 |
| Border | `#d8e6ea` | 淡青线 |

## 字体
标题 Comfortaa 700（圆体）；正文 Open Sans。
中文内容配 Noto Sans SC / Noto Serif SC，中文标题不要斜体。

## 构图特征（Design signature）
1. 首屏右侧是深蓝「Instant quote」卡：卧室 / 浴室 / 频率三组分段按钮，底部实时显示预估价。
2. 服务用薄荷淡底的圆角卡，顶部方形图标块 + 条目清单 + 起价。
3. 服务区域是胶囊标签，含附加费区域用空心胶囊。
4. 套餐三档（每周 / 每两周 / 单次）。

## 不要
- 不要木纹、手绘、暖色（那是 fixit-home / casa-makeover）。
- 不要隐藏价格。
- 不要超过两种强调色。
