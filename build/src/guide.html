1 · Browse and preview / 挑选与预览

  1. Choose Website for templates, effects and page transitions, or Graphic for designs and assets.
  2. Search in the current category, or choose All resources · 全库. Filters apply when browsing one category.
  3. Open a card and read Overview: page list, customization options and what still needs integration.
  4. Preview Desktop, Tablet and Mobile. Compare edits compares the original with your version on desktop; it does not compare different templates.

Use + Compare on template cards to compare up to three different candidates, then open Compare templates.

Live adds preview-only enhancements. Template-native interactions and exported behaviour should be checked in the downloaded files.

2 · Make a project shortlist / 按项目收藏

Tap a heart to add a resource to the active project. Open My list to create or switch projects, add a brief and copy an AI brief for Claude Code or Codex.

Back up projects saves your picks and notes as JSON. Restore backup adds projects without replacing existing ones. These lists live only in this browser; they are not an account or cloud sync. Preview color/font settings are not included in the project backup.

3 · Choose the right export / 选择导出格式

Exports use the current customization settings. Imported full-page templates retain their own CSS and have different customization options. Effects provide snippets; graphics provide fixed-size HTML compositions; assets provide their source file.

4 · Know what is a demo / 分清演示与真实服务

Templates contain example text and business details. A form, checkout or booking page does not imply that email, payment, accounts or a booking backend is connected. Read the item’s notes, replace content and test the complete flow before launching a customer site.

Images, external photos and Google Fonts can require an internet connection. Image counts and placeholder counts in Overview are source-inspection signals, not browser certification. External photographs retain their own licences and credits.

5 · Use Claude Code or Codex / 交给 AI

Start with Copy AI brief in My list. Fill in your goal, audience, real content and absolute project folder. Ask the agent to read the chosen design instructions before exporting.

If design-library MCP is registered in your client: library_overview → search_library → get_template / get_effect → export_site. The local entry is mcp-server/server.py; dependencies are listed in mcp-server/requirements.txt. Claude Code and Codex manage MCP registration separately.

Without MCP, an agent with access to the source project can read library/catalog.json and the resource’s documentation. Online public metadata is available at /api/catalog.json; template files are under /api/website/templates/<group>/<slug>/.

6 · Add resources / 收集新资源

The website is the browsing and reuse interface. Collection happens in the source project: put a resource in _work/inbox/, check its source and licence, classify and import it, then build. Follow AGENTS.md, docs/CONTENT_WORKFLOWS.md and library/FORMAT.md. Website deployment then follows the configured GitHub workflow.

Unclear licences stay in the inbox. local_only resources stay local and must not enter the public site or downloadable source repository.
