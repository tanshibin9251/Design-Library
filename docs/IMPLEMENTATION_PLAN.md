## 批次一：Crumb & Co 图片示范（本轮）

- 使用现有 `cafe-bakery`，保留 Caprasimo / Outfit、奶油底、橄榄绿、红色价格标签与粉笔板。
- Google 搜索发现摄影，回到图片原页确认内容、作者与具体许可；排除付费 Unsplash+、未知来源和搜索缩略图。
- 图片以 HTTPS 远程 URL 嵌入，不把照片下载到 repo 或打包 ZIP；页面和导出包继续保留外链，因此需要联网。
- 补首屏大图、产品特色图、菜单视觉、外烩配图、制作过程和空间示意；FAQ / 隐私等不为凑图加入装饰照片。
- 横图原始尺寸必须宽≥1920、高≥1080，竖图原始短边≥1080；裁切版本也保持至少 1080px 短边。校验原始尺寸，不靠放大请求冒充高清。
- 首图优先加载，其余图片 lazy loading、固定宽高和 aspect ratio；object-fit / object-position 为每个位置调整。
- 背景采用独立的装饰 image 图层，保持可替换和读取状态；信息性照片用 img + alt。加载失败时保留画面比例与明确缺图提示。
- 来源与尺寸记录在模板 images.json，使用说明记录在 TEMPLATE.md；该文件为本模板参考记录，目前不是全库已支持的动态图片管理功能。
- 增加手机导航以保证看图时仍能进入 Menu、Order、Story、Visit。顺带明确原有下单表单是演示，输入和反馈不发送实际订单。
- build、检查公开输出、验证 HTML/PHP 外链导出；390 / 768 / 桌面视觉检查，更新模板缩略图。
- 交付可打开的示范和截图；先看这一套效果，再推广到剩余模板。

## 批次三：全站 layout 与浏览流程

- 手机：压缩顶部介绍和双语重复，优先显示搜索、分类、结果和卡片；预览页次要动作放更多菜单。
- 桌面：行业 / 风格显示常用项，支持展开与分类查找；已选筛选条件可见并能一键清除。
- 搜索：清楚标记范围，提供全库按类型分组的结果；保持中文同义词与返回状态。
- 卡片：除页数外显示适合用途和真实能力；加入必要的图片加载失败提示。
- 详情：用途、页面结构、依赖、素材要求、定制范围、限制和下一步。
- My list：项目集合、备注、JSON 备份与恢复，明确本浏览器存储。
- Compare：将现有版本对比准确命名，另规划最多三套候选模板的横向比较。

## 批次五：全库高清图片推广

1. 按行业列图片需求：Hero / 背景 / feature / 项目 / 产品 / 文章 / 空间。
2. 先摄影型行业：餐饮、家具、室内、酒店旅行、摄影、健康与生活方式；再其它行业。SaaS 主视觉优先真实产品截图，不用随机风景替代产品。
3. 同套图片保持色温、光线和题材一致；产品图必须对应商品，员工/门店摄影必须明确是示意，不能把库存照片说成真实客户案例。
4. 摄影是外链内容，不新增图片下载图库、原图下载按钮或素材再分发包；模板示例保留来源，替换为客户实拍时更新记录。
5. 每个批次登记已覆盖页面和剩余缺图，防止只改首页缩略图。
6. 使用固定照片地址，避免随机图片接口与 Google 临时缓存 URL；外链失效进入维护清单。
